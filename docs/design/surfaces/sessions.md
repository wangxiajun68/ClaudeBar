# 会话与迁移会话

Mode: Operate。原生 macOS SwiftUI，继承 ClaudeBar 的浅冰色／石墨色、系统字体、品牌标识及现有控件。

## 导航与总览

「会话」内部使用 SegmentedCapsule 切换「会话总览／迁移会话」。迁移记录集中到子页面；总览保留 Claude Code、Cursor 和 Codex 分组、懒加载网格、双击继续、目录操作和子代理／工作流。

普通卡片以客户端品牌标识、状态点、项目名称与状态标签开场；任务标题在项目名下只占一行，超长使用尾部省略号，完整内容保留在 help 中。上下文容量、可用的消息数与最近更新时间共用一行，下方是 24 段容量条；它表示真实上下文占用，不表示任务完成度，未知数据明确显示破折号。工具活动与 CPU／内存采样共用一行，Codex 同样显示真实 currentActivity；空活动显示「暂无工具活动」。原资源采样继续复用 SessionLoadChip，Cursor 仍表示整个应用共享进程。卡片移除角落装饰圆环，沿用原来的轻量着色、内框与悬停边缘。

普通卡片内边距 12pt，主要行间距 8pt，上下文读数与容量条间距 5pt，容量条高度 5pt、段间距 3pt。标题使用 14pt 半粗圆体，容量读数使用 15pt 中粗圆体，其余说明沿用系统 caption／caption2，活动与会话 ID 使用系统等宽字体。项目身份与任务标题分开，避免窄卡片被路径前缀占满；不为上下文另起标签行。Codex 的模型与前八位会话 ID 共用一行，完整 ID 在 help 中可见，下一行显示项目路径与动作。Claude 显示模型与终端名称；Cursor 仅在真实 subtitle 非空时增加说明行。迁移、恢复和目录操作统一使用圆形 ActionChip，固定显示，保留 help 和辅助功能名称。

标题下方、上下文读数之前显示累计 Token 与花费主读数。有效数字使用 24pt 加粗圆体与等宽数字，Token 使用可读蓝色，费用使用主文字色；图标及「Token／花费」标签使用较小的 caption2，标签放在数字上方，Token 与花费各占一列；数字单行显示，长金额按可用宽度缩小，缺失数据同样保留 29pt 数字行高度。缺失或未计价状态保持较小的 caption 字体；第二币种与部分未计价说明保留为金额下的小字。它统计 Claude／Codex 索引中该会话及子代理、工作流的已记录总用量，包含输入、输出、缓存读取与缓存写入，不把上下文占用当作累计 Token，也不重复叠加代理流量。Cursor 缺少独立会话的 Token／花费数据，显示「Token 未提供／花费未提供」；Claude／Codex 无索引用量时显示破折号，不将缺失伪装成零。

费用复用 ModelPricing 与现有 Token 单位、币种显示偏好。保留每个历史日的边界，按该日生效价目表估算后汇总；不以今天的价格重算全部历史。显示结果仍有两种币种时，两个金额同时保留。全部无法计价时显示「花费未计价」，部分模型无法计价时在估算金额后标「部分」。原生 help 展示输入／输出／缓存／合计的精确数量、估算口径、非实际账单说明及各模型未计价原因，不扩大卡片常驻说明区。

单个无子代理的 Codex 会话使用普通网格卡片；有子代理时继续使用完整工作区。工作流、代理集群的行为与所有权保持原样。

## 迁移工作台

工作区最大宽度 1120pt，面板上方呈现紧凑的「来源会话 → 创建新会话」。左侧 256pt 来源列表支持按会话或项目搜索，标题预留两行，选择标记固定占位；列表高度 320pt，窄窗口纵向排列时缩为 200pt。右侧六种目标配置使用最小宽度 190pt、高度 72pt 的等高选项，最多三列，保持文字单行和选择标记对齐。宽度不足时纵向排列；提交状态与动作使用 ViewThatFits。来源已在使用的 Claude Code 配置旁明确标注原因。目标选择只进行一次短状态过渡，减少动态效果时禁用动画。

工具调用与结果、用户图片使用 macOS 原生复选框，说明常驻显示，分别解释不会重新执行工具、图片会发送给目标模型以及不携带文档和音频。目标选择下显示具体打开方式与配置来源；官方模型有明确字段标签，自定义模型的供应商／模型采用原生菜单选择，并提供无可用供应商或模型的恢复说明。

预览来自真实生产转换函数；消息总数、大小和用户／助手条数以文字显示，不使用容易被误认作进度的构成条。「查看将携带的历史」展开正文，切换来源收起旧预览。转换遗漏逐项显示。默认不展开消息正文。

迁移记录按现有服务返回的时间顺序懒加载，支持目标筛选、项目／模型／来源搜索、展开详情、再次迁移与打开。保留全部返回记录，不再在界面截断到十二条。「再次迁移」与「打开会话」使用同一套中性操作按钮。

## 状态与隔离

SessionsView 持有 SessionMigrationDraft，草稿跨总览／迁移子页面切换保留；离开迁移页面会取消未完成工作。不承诺跨主导航、关窗或外观重建保留草稿。

来源忙碌／子代理、与来源相同的 Claude Code 当前配置、空对话历史、图片与 Cursor CLI 不兼容、官方模型为空、自定义供应商／模型缺失时禁止提交，并由与提交校验共用的 preparationIssue 说明原因。选择 Cursor CLI 来源时清除其不支持的工具／图片选项。来源、额外内容改变会重新读取预览；版本序号与取消检查阻止旧结果和旧错误覆盖新状态。

新会话写入成功后保留 MigrationRecord，即使打开失败或页面已离开。重试只打开已创建的会话；「新建迁移」显式重置提交结果。独立导航请求 ID 让同一来源的重复点击也能打开子页面。

开发版可浏览流程和选择控件，但不读取外部历史、不准备迁移、不打开目标客户端。副作用入口仍由原 SessionMigrationService 与 TerminalLauncher 的 BuildChannel 闸门保护。

概览的活跃会话卡片复用同一累计用量组件，Token 与花费保持 24pt 大字，标签统一为「Token／花费」；上下文占用改为较小读数并保留进度条。概览只查询当前可见的最多六张卡片，沿用索引与价格变更通知和取消检查。

累计用量由后台任务按客户端各读取一次索引快照，共享给卡片；请求 ID 去重并排序，不逐卡重扫完整日志。Codex 关系识别复用按文件修改时间与大小缓存的元数据头。会话 ID 集合、用量索引或模型价格变化会触发刷新，索引通知合并 500ms；取消后的旧结果不会更新页面。SessionUsageSummary.fetch 在入口执行 BuildChannel 闸门，开发版不查询外部会话用量。

## 验证与预览

- `make test TEST=usage-index`：临时索引验证 Claude／Codex 会话家族、子代理／工作流去重、按日汇总、历史生效价格、缺失与未计价状态及开发版读取限制。
- `make test TEST=session-migration-workspace`：执行生产草稿状态与导航请求函数，验证校验、取消、来源切换、已提交记录保留及打开重试；使用内存 actor，不读写真实客户端。
- `make test TEST='session-migration page-frontend module-scheduling swarm-grid'`：原生历史格式、外部集成限制、列表容器与代理布局回归。
- `python3 Tools/render-session-migration-preview.py`：合成来源、预览和记录；通过 NSHostingView 生成 `.build/session-migration-preview/` 的 760／900／1440pt 明暗及 900pt 空状态图片，保留真实复选框、菜单、输入与滚动视口。
- `python3 Tools/render-session-overview-preview.py`：切片读取真实模型、SessionUsageSummary、SessionUsageReadout 及普通会话卡片、概览活跃会话卡片，使用合成用量调用生产计价函数；生成 `.build/session-overview-preview/` 的 900／1440pt 明暗图片。

迁移页预览使用 NSHostingView 和合成 stores；总览 ImageRenderer 预览将滚动容器展开、文本输入变为同值文本，并省略无法离线绘制的 AppKit 阴影层。总览仅覆盖普通卡片，不覆盖代理／工作流。预览不启动应用、不读取真实历史、不执行迁移。签名与编译验证不代表真实客户端迁移、系统授权、键盘或 VoiceOver 运行验证。

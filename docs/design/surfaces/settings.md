# 设置页

Mode: Operate。原生 macOS SwiftUI；沿用应用浅冰色／石墨色、系统字体和精细工具组件。

## 信息架构

设置按用户目的分为六个主题，避免「通用」成为低频长表的容器。

| 分类 | 保留内容 | 交互 |
| --- | --- | --- |
| 通用 | 登录启动、继续会话的终端 | 开关立即生效；多选项用菜单 |
| 外观与天气 | 配色、天气渲染、城市、问候语与语言、问候字体；自定义天气服务（高德 Key） | 配色双选胶囊；城市提交或失焦保存；密钥显式保存 |
| 灵动岛 | 总开关、两翼、完成提醒、全屏显示 | 开关立即生效；从属项仅在启用后出现 |
| 用量与计费 | Token 单位、币种、按需汇率、模型价格目录 | 少量互斥选项用胶囊；模型价格保留来源、查询、编辑与更新反馈 |
| 权限与隐私 | 会话、通知、系统功能、位置、电池辅助工具 | 应用意图与系统授权状态分别显示；拒绝时保留系统恢复入口 |
| 本地代理 | 启用、端口；高级第三方接入 | 启用立即同步；端口仅在「应用」或回车后验证并重新监听 |

保留现有偏好键和已选值。供应商选择留在模型页、VPN 操作留在 VPN 页；不增加存储实现开关、轮询频率或视觉效果强度等实现项。高德 Key 不是使用天气的前提，放在默认收起的高级服务区；不删除既有配置。模型价格有实际估算价值，独立放进计费分类，而不是堆在通用。

## 视觉与空间

设置容器宽度达到 860pt 时使用 200pt 固定侧栏，侧栏图标与标题组成清晰导航，选中项是带细边的浅色板。右侧独立滚动，内容最大宽 900pt。低于 860pt 收为顶部分类菜单，内容仍按同一阅读顺序排列。主窗口内容视图声明最小宽度 900pt（`MainWindowView` 的 `minWidth`）；设置页没有覆盖紧凑分支的离线预览。

每个分类由 32pt 圆体标题、一句说明和该主题的线条图标开场。每组一个 18pt 圆角面板；标题与图标直接属于面板，组内行靠细分隔线组织。不做逐项卡片、悬浮抬升或常驻动画。状态色只用于分类选中、密钥草稿状态（未保存／已保存）、错误与授权结果。

行标签与控件对齐；紧凑容器放不下时，控件换到标签下方。开关用应用的 InstrumentToggleStyle；少量互斥选择用 SegmentedCapsule；文本输入以 InstrumentFieldStyle 为主（问候语自定义内容与字体搜索用系统默认样式）；较多枚举用原生菜单配 InstrumentMenuLabel；提交动作用 ActionButton。授权状态不是普通偏好值，保留独立的说明、状态与系统入口。

## 草稿与依赖

- 普通城市文本在回车、失焦或离开外观分类时保存。
- 高德密钥只在「保存」或回车时提交；切换分类不保存。未保存／已保存状态明确。
- 端口切换分类不提交。无效输入保留原端口并显示范围说明；应用有效值后才重启代理。
- 关闭天气渲染后，相关天气配置不触发查询；字体仍独立可选。
- 手动城市也是当前位置不可用时的备用城市，允许编辑。
- 货币分列不需要汇率；换算模式才展示汇率控制。
- 系统权限不自动请求，只有用户操作对应功能或授权动作时触发。

`MainWindowView` 以 `@StateObject` 持有 `SettingsState`，位于 `.id(appearance)` 的外观重建边界之上，再传入设置页。分类、城市／密钥／端口草稿、端口错误和高级区展开状态因此可跨分类、主页面导航及配色切换保留；显式保存的密钥与端口不会因导航自动提交。状态仅属于当前主窗口生命周期，不承诺关闭窗口后恢复未保存草稿（宿主由 `MainWindowController.releaseContent` 在关窗时拆除）。

## 验证

`Tools/render-mainwindow-preview.py` 渲染概览、会话、用量、VPN、流量五页，不含设置页；设置页没有离线预览入口。草稿语义由源码保证：密钥只在「保存」或回车时提交，端口只在「应用」或回车后验证并重新监听。

构建经 `Sources/build.sh`（`CLAUDEBAR_SKIP_INSTALL=1`，不安装）完成；保留当前运行中的应用与 VPN。该流程验证编译与打包，不覆盖安装、真实系统授权或代理重新监听。

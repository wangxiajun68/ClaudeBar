# 设置页

Mode: Operate。原生 macOS SwiftUI；仅重构设置页，沿用应用的浅冰色 / 石墨色与系统字体。

## 目标与结构

让用户按目的找到一个偏好并修改，不用在诊断卡、运行状态和接入说明之间寻找开关。

顶部分类固定，内容区独立滚动，切换分类回到顶部：

| 分类 | 内容 |
| --- | --- |
| 通用 | 外观、登录启动、继续会话的终端；Token 单位与货币；天气城市与问候字体 |
| 灵动岛 | 总开关；启用后显示两翼、完成提醒和全屏显示 |
| 权限与隐私 | 会话与通知、系统功能、位置；电池辅助工具授权 |
| 本地代理 | 总开关与监听端口；按需展开第三方接入地址、示例、流量记录和供应商 |

## 视觉规则

- 内容最大宽 800pt，左右外边距 32pt，大窗口中居中。每组一个白色或深色面板，12pt 圆角、1pt 细边，无悬浮、光圈与逐项彩色图标。
- 标签左对齐、控件右对齐。行内水平间距 24pt，内边距横向 20pt、纵向 15pt；组间 24pt。
- 页标题 26pt，组标题与标签 13pt，说明 12pt；警告可以换行，不截断恢复操作所需的说明。
- 使用 macOS 原生开关、菜单和分段选择器。颜色用于已开启状态与错误。各控件保留可访问性名称，权限状态另行标注。
- 版本号、日志与帮助降为页脚辅助信息。

## 精简清单

- 删除设置页的 SQLite/JSON 存储实现开关，沿用用户现有配置，不迁移或清空数据。
- 删除 VPN 重复启停入口，VPN 页仍负责管理 VPN。
- 删除独立的供应商连通性卡与 Cursor 状态卡；模型相关操作在模型页，Cursor 数据开关统一在权限页。
- 删除五条原始配置文件入口和设置页退出按钮；保留帮助与日志入口，应用菜单仍可退出。
- 删除无操作的「鉴权：令牌」卡，接入说明与带令牌示例合并为一行。
- 删除 Claude Code / Codex 只读上游卡；第三方供应商仍可独立选择。
- 大型字体画廊收为一行菜单，保留所有现有字体选项和已选值。原画廊实现与字体资源不在此次清理范围。
- 移除设置页每 5 秒扫描配置目录与已安装终端的任务；终端列表在页面出现、应用回到前台时刷新。

## 行为与验证边界

设置绑定沿用原有持久化键、代理同步、启动授权和权限中心。城市与端口在提交或失焦时生效；切换分类也提交草稿。端口错误显示说明并保留原端口，不再把非数字字符静默剔除。手动汇率改为在真正失焦时提交。

已完成修改文件的 Swift 语法解析与引用检查。按用户要求未 build、安装或重启，因此修改后界面的实际渲染、完整类型检查、键盘交互及浅深色视觉验收需在用户允许构建后完成。

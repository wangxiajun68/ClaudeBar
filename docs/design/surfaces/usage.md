# 用量分析

Mode: Operate。原生 macOS SwiftUI，分析已有本地记录；以明确的读数层级、整齐的共同比例尺度和可检查的真实数据为目标。

## 信息与空间

周期工具栏将前后切换、日期、周期选择和刷新放在同一行；自定义日期选择器按需出现。其后五项读数为本地 Token、有记录的天数、日用量中位数、日用量 P95、缓存命中率。每项采用标签在上、25pt 半粗体圆角等宽数字在下的排版，宽窗口横向均分，放不下时以两列排列；口径解释通过原生帮助文字提供。

分析区域使用全部可用宽度：指标、用量节奏、来源与 Token 构成、模型关系、展开统计依次排列。用量节奏与模型关系各自全宽。来源份额与 Token 构成通过 `ViewThatFits` 在双列与单列间切换，双列各自最小 400pt，两张面板均固定为 294pt 高，标题、数值列与底部说明对齐。窄窗口按来源、Token 顺序叠放。面板间距为 14pt，内边距为 20pt，圆角为 16pt；时间轨迹画布高 138pt，分布画布高 118pt，分布面板高 190pt。日历仍按实际周行数自适应高度。

视觉沿用 SF 系统字体和 Theme 的浅深背景，统一使用柔和蓝、青绿、紫色和珊瑚色区分类别。图形采用带实心观测点的轨迹、面积气泡、双层环、关系弦图、雨云分布与 Lorenz 面积；图形旁提供实际数量和百分比，避免只靠颜色解读。平台、供应商、模型和官方账单位于默认展开的「记录明细」，仍可手动折叠，保留全部既有操作。分析面板不加悬浮抬升或装饰动画。

## 数据口径

| 项目 | 当前实现 |
| --- | --- |
| 本地总量 | 模型记录中输入、缓存读取、缓存写入、输出之和，不包含 Cursor 官方账单 |
| 时间记录 | `DayUsage` 按日期合并；已到达且无记录的日期记零，未来日期排除 |
| 日／月／自定义 | 按日观测；单日没有小时采样 |
| 年／全部 | 按月汇总；全部周期超过 730 个已到达日期时按年汇总 |
| 全部起点 | 第一条本地日期记录；没有日期记录时从今天开始 |
| 日 P50／P95 | 包含零记录日，排序位置 `p × (n − 1)`，相邻值线性插值；显示转为整数 Token |
| 桶中位数 | 当前显示粒度的桶中位数，不等同于始终按日计算的指标 P50；分析模型保留该值，主图不绘制中位线 |
| 缓存命中率 | 缓存读取 ÷（输入 + 缓存读取 + 缓存写入）；分母为零显示破折号，输出不入分母 |
| 桶 P25／P75 | 当前显示粒度的桶分位数，包含零桶，与日 P50／P95 使用同一线性插值算法 |
| 周期分布 | 真实观测保留重复值及零桶；样本不足时按每个实际数值汇总精确频数，不划分直方图区间 |
| 核密度估计 | 至少 5 个桶且至少 3 个不同数值时计算高斯 KDE，采用 Silverman 带宽与零边界反射；密度形状明确标为样本估计 |
| ECDF（保留数据） | 当前粒度每个桶作为一次观测；`F(t) = count(Token ≤ t) / 桶数`，合并相同值的阶跃，保留零桶；界面不再显示 |
| 模型份额 | 模型总量 ÷ 所有正值模型总量；显示 Top 8 不重新归一化 |
| 模型来源关系 | 连接量为对应模型与来源的实际 Token；图形连接量与模型汇总总量保持各自数据范围 |
| Lorenz | 全部正值模型按 Token 升序，横轴累计模型比例，纵轴累计 Token 比例，从原点到 100% |
| 有效模型数 | `1 / Σp²`，p 为全部正值模型的 Token 份额；无模型为 0，等权时等于模型数 |

时间记录、模型汇总和来源汇总保持各自实际数据范围。成本估算和 `Cursor 实扣` 分别标注，不相加，不从本地 Token 推测缺失账单或节省金额。

## 用量节奏：观测轨迹与日历

多周期主图按当前粒度绘制 3pt 蓝色折线、实心观测点和蓝色填充面积。折线只线性连接实际日期桶，不平滑制造额外峰谷；面积强化实际用量轮廓，不表达置信区间。普通点半径为 3.5pt，峰值或检查点半径为 5pt，峰值使用珊瑚色。默认原值纵轴从零开始，顶部读数显示日期记录合计，悬停后改为对应桶的数量与日期，下方提供完整 Token 和缓存命中率。轴线与刻度保留，横轴疏排约 8 个日期标签；每个周期以原生按钮提供等价的辅助功能读数，按日时可点击下钻。

只有一个有用量的日期桶时改为量化摘要：左侧 114pt 圆形日期，右侧 34pt 实际 Token，以及提示侧、输出和缓存命中读数，明确当前只有一个观测周期，不构造小时趋势。全部已到达周期均为零时压缩为 0 Token 及周期数说明，不保留空的大幅画布；其余多周期轨迹仍保留零桶。没有已到达日期时显示空日期文案。

标题行的原生图表菜单切换轨迹／日历，多桶时可选择「长尾」坐标 `asinh(Token / c)`，c 为正值桶的插值中位数，至少为 1。长尾坐标保留零原点，轴标签通过 `sinh(x) × c` 还原成原始 Token，界面明确标注当前尺度。深浅主题分别定义图形颜色。

「日历」切换替代时间轨迹。始终展示日总量，最多取最近 366 个已到达日期；截取提示明确，指标和其他图仍覆盖整个周期。摘要的活跃日、日均、峰值及日期范围仅取当前可见日期，不混用模型汇总总量。

最多 31 日时使用横向铺满的七列周网格，取消 34pt 单元格宽度上限及居中画布。38pt 高的日期格包含日期和 Token 数字；窄格优先保留日期，完整数值仍在悬停帮助与辅助功能中提供。范围外的位置是中性占位，不伪造邻月或未来日期。第八列展示范围内的周合计数字，面板高度由实际周数决定。日期格与周合计直接显示真实数量。

长周期按周列展开，热带使用全部可用宽度。当每周有至少 64pt 宽度时，格内展示日期和用量；列数较多时改为 12pt 高密集热格和疏排月标签。短密度模式高 122pt，详细模式高 238pt，不给热带保留多余的大面积画布。Canvas 点击与悬停命中排除格间缝隙及范围外位置。

零值为灰色，正值强度使用 `log1p(99 × value / visibleMaximum) / log(100)` 的相对长尾尺度，避免十亿级数值在绝对 `log1p` 归一化后全部挤入亮黄端；映射到 viridis 紫—蓝—青绿段的 48 个样本，深色主题使用相同提亮色表。图例显示「强度」、色阶及可见峰值；数量由数字提供。日期格采用该色相的浅底色与细边，正文仍使用 Theme 的可读文字色。悬停边线以 140ms 一次性过渡，尊重减少动态效果；没有循环动画。月网格采用原生按钮支持键盘操作；点击日期、「选择日期」菜单及长周期辅助功能日期按钮均可下钻。

## 来源、模型、Token 构成与展开统计

来源份额使用面积气泡：每个正值来源的半径与 `sqrt(sourceTokens / sourceTotal)` 成正比，同一面板共享尺寸尺度，所以圆面积与真实 Token 成正比。零值来源不绘制气泡，下方三行仍将所有类别、数量、份额对齐；气泡较大时直接显示份额，帮助文字提供完整 Token 数。底部显示来源总量并注明不包含 Cursor 官方账单，无记录时显示相应文字。气泡大小不添加人为最小份额，也不量化为等权点数。

「模型 × 来源」使用 280 × 260pt 关系弦图与模型名单。最多取 8 个模型，按全部本地 Token 降序排列；来源环弧与模型环弧位于两侧，中心填充连带连接实际匹配的来源 Token。所有连接共享同一角度尺度，每条连带在来源端与模型端的角跨度相等，并与对应单元的真实 Token 成正比。节点间隙只用于分隔，不增加小值或零值的跨度；零连接不绘制。环弧以来源颜色和模型序号对应旁边的名单，无匹配来源时显示文字说明。

弦图的几何分母为所展示 Top 模型的匹配来源记录总量；模型名单的总量与份额仍来自全部本地模型汇总，Top 8 不重新归一化，也不以连接图的总量替代模型总量。名单逐项显示模型名、数量、份额与真实来源值，帮助文字保留精确数字。宽窗口弦图与名单并排，窄窗口按图、名单顺序叠放，来源值自身也可改为竖排；底部显示有效模型数并说明连接与模型份额的不同口径。

Token 构成使用双层环：外环为输入、缓存读取、缓存写入、输出四类互不重叠的 Token，内环为提示侧与输出，两个环各自都以全部本地 Token 为分母。弧度直接按 `tokens / total × 2π` 绘制，不添加最小份额或固定角度间隙；零值不占弧度。环旁四行显示类别、数量与份额，帮助文字提供精确完整 Token 数；环心显示缓存命中率，底部说明内环口径。提示侧为输入、缓存读取与缓存写入之和，缓存命中率不含输出。全零时使用中性空环。

默认折叠的「分布与集中度」展开为周期雨云分布与模型 Lorenz 集中度，宽窗口并排、窄窗口叠放。样本充分时雨云图以同一个线性 Token 横轴叠加真实观测点、P25–P75 中间 50% 区间和中位点；观测点的纵向分层只用于减少重叠，不编码另一种测量。样本不足时仍在图下显示真实的 P50 与 P25–P75 读数。

只有至少 5 个桶且至少 3 个不同用量时才绘制估计密度，标题明确标注「核密度估计」。采用高斯核、Silverman 带宽 `max(1, 0.9 × scale × n^(-1/5))`；scale 取样本标准差与 `IQR / 1.34` 的较小值，IQR 为零时使用标准差。密度使用零边界反射，绘图区从非负下界至最大观测值加三倍带宽，以 96 个采样点描绘形状；密度峰值仅用于形状归一化，不当作周期数或概率置信带。样本不足时按每个实际数值绘制频数气泡，气泡内显示精确周期数，所有观测相同时明确显示无分布差异，不伪造平滑密度。ECDF 数据保留用于重复值的精确累计统计，界面不再绘制阶跃曲线，也没有跨图联动检查。

Lorenz 仍基于全部正值模型，不受 Top 8 截取影响。采用 3pt 紫色曲线、实心累计点与下方面积，并给出完全均衡虚线；横轴为累计模型份额，纵轴为累计 Token 份额。模型按用量升序，填充区强调实际累计轮廓与偏离均衡的程度，不表达置信区间。上方以大号读数显示有效模型数与实际模型数；无模型或只有一个模型时显示文字说明。

## 记录明细：恢复原有卡片

平台、供应商、模型及 Cursor 卡片恢复调整前的曲线、字体、金额位置和展开详情结构，保留明细默认展开及正确的占比精度、平台数量。供应商和模型卡片的曲线是视觉装饰，帮助文字明确它不代表逐日统计；实际时间图仅在上方主分析区域。平台卡片的原有小曲线取来源日记录，不将 Cursor 官方账单补造为本地逐日记录。

Cursor 恢复四类 Token 精确数值、模型明细和实际账单查询区间；刷新失败保留数据的提示不隐藏。Cursor 不进入本地平台份额，刊例估算与 Cursor 实扣仍使用原有独立逻辑。

## 状态与性能

只有已发布记录区间与当前选择一致时展示统计，否则显示读取状态。输入变化时以独立任务计算分析、经验分布、核密度、Lorenz 点列、来源总量和模型来源数据；取消后的结果不发布。桶极值与分布参数预先缓存，悬停仅检查缓存结果，不重聚合记录。切换数据后清空日期检查选择。

## 研究来源、署名与验证

本轮图表研究参考 [Apple Charts HIG](https://developer.apple.com/design/human-interface-guidelines/charts) 与 WWDC22 [Design an effective chart](https://developer.apple.com/videos/play/wwdc2022/110340/)，采用明确摘要、可检查数量、受控轴密度和辅助功能读数。[Anthropic 官方品牌指南](https://github.com/anthropics/skills/blob/main/skills/brand-guidelines/SKILL.md) 的珊瑚色 `#D97757` 与柔和蓝 `#6A9BCC` 提供分类配色方向，原生界面仍使用 SF 字体与现有 Theme，浅深主题分别定义图形颜色。

[Nature 图形规范](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/) 提供清晰轴线与刻度、可读标签、颜色图例及减少重叠和多余装饰的参考。[Observable Plot Dot](https://observablehq.com/plot/marks/dot) 展示以面积编码数量的圆点语法，其半径通道默认使用平方根尺度；[D3 Arc](https://d3js.org/d3-shape/arc) 说明以起止角度、内外半径构造环形分段。本实现借鉴这些数据表达方法，并按原生应用的可读性与交互调整，不宣称已符合期刊发表或导出规范。

[Matplotlib 官方 Choosing Colormaps](https://matplotlib.org/stable/users/explain/colors/colormaps.html) 说明顺序色阶适合有序值，并将 viridis 列为感知均匀色阶。[Matplotlib AsinhScale 文档](https://matplotlib.org/stable/api/scale_api.html#matplotlib.scale.AsinhScale) 提供零附近近似线性、较大数量渐近对数的尺度依据；本实现使用明确的 `asinh(Token / c)` 公式和逆变换标签。应用不引入图表研究工具的运行时依赖。

viridis 作者 Nathaniel J. Smith、Stefan van der Walt、Eric Firing 的 64 个采样颜色数据采用 CC0／公有领域奉献，署名及 BIDS 色表来源记录在 `Sources/ClaudeBar/Resources/ASSET-LICENSES.md`。应用不打包 Matplotlib 运行时。

实现依据为 `Sources/ClaudeBar/Utils/UsageAnalysis.swift`、`Sources/ClaudeBar/Views/Shared/UsageAnalytics.swift`、`Sources/ClaudeBar/Views/Shared/UsageDistributionPlot.swift`、`Sources/ClaudeBar/Views/Shared/UsageRelationshipPlot.swift`、`Sources/ClaudeBar/Views/Pages/UsageView.swift`。本文记录当前源码的布局和数据口径；数量来自记录，不补造小时趋势、缺失日期记录、账单或节省金额。离线合成记录静态预览位于 `.build/usage-redesign`，覆盖浅色、深色、窄窗口、多周期、全零与无已到达日期场景，用于检查布局、图形比例与主题。预览只覆盖所渲染的记录与窗口尺寸，不执行应用生命周期、原生菜单或悬停交互，不能视为实际运行验证。本轮最终构建、回归与预览结果以交付说明为准；未启动应用或执行 VPN、系统代理、DNS、TUN、硬件及其他系统集成验证。

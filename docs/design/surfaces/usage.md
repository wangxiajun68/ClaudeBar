# 用量分析

Mode: Operate。原生 macOS SwiftUI，分析已有本地记录；以紧凑的信息密度和可检查的统计图形为目标。

## 信息与空间

周期工具栏将前后切换、日期、周期选择和刷新放在同一行；自定义日期选择器按需出现。其后五项读数为 Token、记录日、日 P50、日 P95、缓存命中，采用 17pt 半粗体等宽数字，不再常驻说明行。解释通过原生帮助文字提供，指标放不下时以两列排列。

主分析只有两个面板：活动剖面，以及来源 × 模型。面板使用 14pt 内边距、8pt 内部节奏和 10pt 外部间距，沿用中性背景与细边。活动图可用宽度达到 700pt 时，轨迹与 ECDF 按 64:36 分配宽度，列间距 16pt，避免宽窗口把轨迹拉得过长而分布图过窄；矩阵最小宽 480pt，右侧 Lorenz 为 240pt，列间距 16pt。`ViewThatFits` 在放不下时按同一顺序叠成单列。轨迹与 ECDF 图高 174pt；Lorenz 图高 135pt；替代日历高 174pt。

平台、供应商、模型和官方账单位于默认折叠的「记录明细」，展开保留全部既有操作。分析面板不加悬浮抬升或装饰动画。

## 数据口径

| 项目 | 当前实现 |
| --- | --- |
| 本地总量 | 模型记录中输入、缓存读取、缓存写入、输出之和，不包含 Cursor 官方账单 |
| 时间记录 | `DayUsage` 按日期合并；已到达且无记录的日期记零，未来日期排除 |
| 日／月／自定义 | 按日观测；单日没有小时采样 |
| 年／全部 | 按月汇总；全部周期超过 730 个已到达日期时按年汇总 |
| 全部起点 | 第一条本地日期记录；没有日期记录时从今天开始 |
| 日 P50／P95 | 包含零记录日，排序位置 `p × (n − 1)`，相邻值线性插值；显示转为整数 Token |
| 轨迹中位线 | 当前显示粒度的桶中位数，不等同于始终按日计算的指标 P50 |
| 缓存命中率 | 缓存读取 ÷（输入 + 缓存读取 + 缓存写入）；分母为零显示破折号，输出不入分母 |
| ECDF | 当前粒度每个桶作为一次观测；`F(t) = count(Token ≤ t) / 桶数`，合并相同值的阶跃，保留零桶 |
| 矩阵模型份额 | 模型总量 ÷ 所有正值模型总量；显示 Top 8 不重新归一化 |
| Lorenz | 全部正值模型按 Token 升序，横轴累计模型比例，纵轴累计 Token 比例，从原点到 100% |
| 有效模型数 | `1 / Σp²`，p 为全部正值模型的 Token 份额；无模型为 0，等权时等于模型数 |

时间记录、模型汇总和来源汇总保持各自实际数据范围。成本估算和 `Cursor 实扣` 分别标注，不相加，不从本地 Token 推测缺失账单或节省金额。

## 活动剖面：轨迹与 ECDF 联动

轨迹采用蓝色折线、低透明度蓝色面积及观测点。折线保持线性插值，不平滑制造观测之外的峰谷；面积只用于强化实际用量轮廓，不表达置信区间。点的蓝到青连续色阶对应提示侧缓存命中率，图例固定为 0–100%，与绘制点使用相同端点和线性 RGB 插值；无提示量的观测用灰色，不将未定义命中率当作零。标题直接显示当前粒度峰值，中位虚线标出 P50 和实际 Token。连线只连接统计周期，辅助功能说明其不表达小时采样。

默认「长尾」坐标为 `asinh(Token / c)`，c 是正值桶的插值中位数，至少为 1。零值保留在原点，轴刻度通过 `sinh(x) × c` 还原成原始 Token 标签。「原值」使用从零开始的线性 Token 坐标。轨迹纵轴与 ECDF 横轴使用同一变换；中位线也通过相同变换绘制。全部零桶仍显示真实零轨迹和零处的经验阶跃；仅没有已到达日期时显示空日期文案。

ECDF 采用青色阶梯线与浅色面积；50% 和 95% 水平参考线直接标注累计比例。ECDF 是经验阶梯函数，纵轴为不超过横轴 Token 的桶比例，涵盖重复值和零值。它描述当前已记录周期的分布，不是 KDE、预测或置信带，日 P95 也不宣称实测覆盖率。悬停或点选轨迹检查对应日期桶，ECDF 同步标示总量；在 ECDF 检查 Token 时，轨迹突出当前变换坐标中最近的观测桶。相同 Token 的多个桶均保留在统计中，检查仅选择其中一个实际桶。联动文字显示日期、完整 Token、提示侧命中份额和经验累计比例。

「日历」切换替代轨迹／ECDF，而非新增常驻图。始终展示日总量，最多取最近 366 个已到达日期；截取提示明确，指标和其他图仍覆盖整个周期。短范围采用带日期的月历，较长范围按周列排列。零值为灰色；正值强度 `log1p(value) / log1p(visibleMaximum)` 映射到 64 个 viridis 样本，图例使用同一组颜色与可见最大值。悬停显示完整数字，点击日历或「选择日期」菜单下钻到单日，辅助功能日期按钮提供同等动作。

## 来源 × 模型：条形矩阵与集中度

最多 8 个模型按全部本地 Token 降序，标题显示实际展示数量；矩阵三列为实际来源，每列标题同时显示该来源的总 Token 和固定类别色标。每格为精确数值及 4pt 条形，所有单元格共用 `Token / matrixMaximum` 的线性长度尺度；类别色区分来源，数量通过条长读取，不再使用大片对数色块。零值保留短横与中性底轨；极小份额不加最小条长，其实际数字始终可见。矩阵使用 10pt 列间距、6pt 行间距、4pt 单元格圆角；原生帮助及辅助功能提供完整 Token 数字。

行末份额以全部模型总量为分母；零为 `0%`，正值不足 0.1% 显示 `<0.1%`，其余保留一位小数；数字下方的细条使用真实份额，不重新归一化 Top 8。底部注明共同线性尺度和矩阵最大值。轨迹的缓存率色阶、矩阵的来源类别色和日历的日总量色阶各自标注口径，不能跨图以同色推断同量。

Lorenz 曲线使用全部正值模型，而非 Top 8；蓝色曲线与完全均衡虚线之间的浅蓝面积表示偏离均衡的程度，不是统计置信区域。没有模型或只有一个模型时显示相应文字。标题展示首位份额与有效模型数／实际模型数，帮助文字解释 inverse Simpson 公式和等权参照。

## 状态与性能

只有已发布记录区间与当前选择一致时展示统计，否则显示读取状态。输入变化时以独立任务计算分析、经验分布、Lorenz 点列、来源总量和矩阵；取消后的结果不发布。桶极值和矩阵最大值预先缓存，悬停仅检查缓存结果，不重聚合记录。切换数据后清空联动选择。

## 研究来源、署名与验证

[Matplotlib 官方 Choosing Colormaps](https://matplotlib.org/stable/users/explain/colors/colormaps.html) 说明顺序色阶适合有序值，并将 viridis 列为感知均匀色阶。[Matplotlib AsinhScale 文档](https://matplotlib.org/stable/api/scale_api.html#matplotlib.scale.AsinhScale) 提供零附近近似线性、较大数量渐近对数的尺度依据；本实现使用明确的 `asinh(Token / c)` 公式和逆变换标签。[SciPy ecdf 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ecdf.html) 定义经验阶梯分布与重复观测的累计概率；本实现根据当前桶的精确记录生成阶跃，不调用 SciPy 运行时。

viridis 作者 Nathaniel J. Smith、Stefan van der Walt、Eric Firing 的 64 个采样颜色数据采用 CC0／公有领域奉献，署名及 BIDS 色表来源记录在 `Sources/ClaudeBar/Resources/ASSET-LICENSES.md`。应用不打包 Matplotlib 运行时。

实现依据为 `Sources/ClaudeBar/Utils/UsageAnalysis.swift`、`Sources/ClaudeBar/Views/Shared/UsageAnalytics.swift`、`Sources/ClaudeBar/Views/Pages/UsageView.swift`。本文记录当前代码事实。此次蓝青轨迹／ECDF／条形矩阵／Lorenz 调整按用户要求仅交付源码；最终密度调整后未再编译，未完成原生渲染与交互验证。不承诺所有窗口宽度、深色模式或实际运行已经验证。

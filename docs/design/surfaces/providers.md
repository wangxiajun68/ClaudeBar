# 供应商管理

Mode: Operate. 原生 macOS SwiftUI。供应商目录优先，保留冰色／石墨底色与系统圆体。

模型页提供「供应商 / 自动网关」两个工作区。自动网关沿用 `SettingsGroup`、`SettingsRow`、`InstrumentField`、原生菜单及现有按钮；池内条目以完整模型 ID、供应商、免费来源、能力和文字状态呈现。设置、接入、模型池、已有供应商提交、OpenRouter 发现和路由记录置于单个滚动页面。窄窗口的设置行由现有 `ViewThatFits` 折为上下两行；完整 ID 可换行和选中，凭据只在已有供应商编辑器维护。模型池的路由状态只在页面可见时读取，模型发现归应用生命周期。详见 [Auto 网关](../../LLM_GATEWAY.md)。

## 布局和状态

自动网关的模型池条目直接展示低／中／高难度复选框，可多选；已有供应商提交表单也可设置难度。接入区以不带难度的 Auto 请求为默认示例，说明本地规则判断、medium 保守兜底与可选 `task_difficulty` 覆盖；路由记录展示任务类型、判断来源、升档／选择原因、实际模型与难度，避免只靠颜色区分档位。

页面标题为「模型」；Claude Code / Codex 切换、分类、搜索同排，标题右侧是导入对端配置与「自定义」新增入口；窄窗口将分类收为菜单（`Picker`）。下方紧凑状态行展示当前连接、已保存配置数量与「仅显示已配置」开关。目录按模型平台、Coding / Token Plan、聚合与自建分组；激活中的卡片从所在分组移到目录顶部的「当前激活」区，未匹配的接口留在「自定义供应商」区。图标离线打包。

所有卡片统一 216pt，区域为厂商信息、模型选择、状态协议、操作。灰色未配置、琥珀色待完善、蓝色已配置未激活、绿色已激活；搭配文字图标，不只依赖颜色。状态由保存的配置决定，待选模型不会改变状态。悬停改变表面色调、轮廓与阴影，并把卡片抬高 2pt（`offset`，不占用布局空间），关闭减少动态效果时取消位移；卡内按钮按压有弹簧反馈与轻微缩放。

抓包控制使用 30pt `ActionIcon`，以捕获角框与双向数据流组成自有 `capture.requests` 图形。绿色实心状态点表示开启，灰色空心点表示关闭，配合图形色调和细边区分状态。悬停提示说明该供应商的请求报文写入「流量」页，并保留供应商名称与“开启／关闭”的辅助功能值。状态直接读取已保存供应商的 `captureEnabled`，与编辑弹窗和 CLI 共用来源，待选模型或本地按钮状态不替代它。

## 配置：聚焦弹窗

点击已有供应商的配置按钮直接打开单供应商编辑弹窗（640×680），不显示页面右侧详情，也不显示弹窗内的供应商导航栏。复用原编辑模型，保留 Key、地址、协议、高级模型设置与拉取模型等能力。保存才提交表单修改，编辑当前激活供应商时沿用原同步更新逻辑。关闭按钮明确说明未保存修改不提交。多供应商管理就是目录页本身，不再有第二层入口。

新预设使用“连接凭据 → 模型 → 保存”弹窗，不自动激活。普通文本 Key 输入失焦遮蔽，不使用系统 Passwords 控件。

## 激活：先选目标，再提交切换

卡片中间整块区域显示目标模型与所属配置，标为“当前使用”或“待激活”。点击打开搜索浮层：按配置分组、显示完整模型 ID、标记实际使用中的模型以及待选项，支持搜索、上下键和回车。不可用配置显示待完善并禁止选择，空搜索结果给出提示。

选择模型只更新卡片的临时目标并关闭浮层；点击独立激活按钮才调用原有切换流程。默认目标为当前配置的活动模型或首个可用配置的默认模型。即使供应商已激活，选择另一个模型后仍可激活。只有供应商和模型都与当前一致时显示“已激活”并禁用重复操作。模型被删除时不保留悬空 ID，重新从现有配置解析目标。激活失败由现有错误区域显示，未成功写入时不提前标绿。

“官方”是模型平台第一张内置卡片，激活复用还原逻辑；保留已保存供应商，不伪造 Key 或官方模型 ID。模型选择由官方客户端管理。其默认状态表达没有选中的第三方配置，不验证官方登录。

## 交互依据与取舍

- [CC Switch 切换说明](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/en/2-providers/2.2-switch.md)：明确启用动作，写入后更新当前状态。
- [CC Switch 添加说明](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/en/2-providers/2.1-add.md)：预设填入连接信息，模型列表可拉取选择。
- [Open WebUI 模型选择](https://docs.openwebui.com/features/workspace/models/)：搜索式模型选择器，区分可用模型。

本实现将“选择待激活目标”和“写入客户端配置”明确分开，这属于本项目的交互取舍，并非照搬参考项目行为。

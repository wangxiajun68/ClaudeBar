# 飞书文档工作区

Read / Operate。正文阅读使用飞书官方云文档组件（WebKit 宿主），其余界面与编辑沿用原生 SwiftUI、AppKit 与 Theme，不加载第三方编辑器运行时。

## 阅读

正文默认使用官方云文档组件（`DocComponentSdk 1.0.13`）呈现原版排版、图片与表格；只读、隐藏头部导航与点赞、链接在系统浏览器打开。组件加载失败时显示失败原因，并切回原生 Markdown 阅读器；失败栏提供「重试原版」重新装配组件。组件仅覆盖文档的阅读态：原始 Markdown 草稿、整篇源码模式与其他文件类型继续使用原生阅读器。

原生渲染的排版与编辑：

正文 15pt、段落行距 7pt，正文行宽最多 740pt；表格可以使用更宽的画布。
H1–H6 分别为 32 / 25 / 20 / 17 / 15 / 14pt semibold，以字号与段前空间表达层级，移除正文中的 H 标签。
目录沿用真实标题锚点与层级；容器不足 850pt 时改为弹出目录，避免侧栏挤压正文。

列表保留嵌套缩进，相邻列表项收紧行距；HTML 有序列表保留 start / seq。任务使用圆形勾选框，引用使用色条。
高亮块保留 emoji、背景色和边框色，内部段落与列表继续按块排列。分栏按 width-ratio 并排。@人、@文档、下划线、文字色、背景色和行内公式按飞书 XML 呈现。
书签、按钮、日期、画板源码（Mermaid / PlantUML / SVG）和附件使用信息卡；没有本地资源的嵌入内容保留飞书查看入口。
行内代码使用等宽字体与中性底色，链接使用可读的 Theme.Ink.claude。
表格保留实际 rowspan / colspan 拓扑，表头、交替行底色与连续框线帮助定位。
长表格横向滚动；单元格根据多行内容量高，合并单元格参与行高计算。

## 编辑

官方组件回退后或正在编辑草稿时，正文使用原生排版。点击标题、段落、列表、任务、引用、提示块或代码后，该块换成内容尺寸的原生 NSTextView 并放入光标；方向键移到相邻可编辑块。
表格先按合并单元格排版，再点击单元格输入。不要求编辑按钮、双击、编辑弹窗或切换全篇布局。
保留中文输入法组合文字、选择、复制粘贴、原生撤销与重做；Cmd+B / Cmd+I 修改选中文字格式。
普通点击链接直接打开，Option+点击进入链接文字编辑；支持 HTTP、HTTPS 和 mailto，
自动识别正文裸链接，代码中的 URL 保持字面内容。
Tab / Shift-Tab 在表格单元格间移动，末格 Tab 添加一行。

表格列边缘可以拖动调整列宽，行边缘调整行高；内容高度是避免截断的最小值。
右键可增删行列、合并右侧或下方的兼容单元格、拆分、切换表头、调整框线粗细及自动适应内容。
尺寸与结构变化进入原生撤销栈，序列化为 HTML 的 col / tr 尺寸及 rowspan / colspan。
未修改单元格保留原始内部 HTML（包括尚不支持编辑的 mention / token 等资源）。

首次实际修改自动建立内存草稿，正文一直保持排版，保存按钮或 Cmd+S 同步到飞书。
不再为正常保存额外弹出确认；丢弃与删除等破坏性操作仍确认。
保存保留账号、revision 校验与失败时草稿保留。服务端使用全文替换，
修改的文本块会规范化其行内格式，无法保证飞书的所有高级样式与评论锚点原样保留。
内存草稿不会跨应用退出保存，退出前需保存或复制。

整篇源码阅读与编辑仍是显式工具；阅读态可通过工具栏在排版与源码之间切换。原生阅读路径中，超过 512KB 的正文一律使用源码视图（`FeishuDocumentEditor`），不进行 Markdown 排版；官方组件不受该上限限制。
源码范围以 UTF-16 定位并验证 Unicode scalar 边界，局部修改保留未编辑部分的
原始 Markdown / HTML、frontmatter 与换行；HTML 容器子块使用独立叶节点范围。
新建空白草稿在正文排版中直接输入（空首段显示占位文案）。保存期间锁定输入，不替换正文渲染器或重置整页布局。公开 HTTPS 图片可预览；白板、私有图片与其他嵌入资源保留占位及飞书查看入口。

## 验证

`make test TEST=feishu-documents` 运行真实生产解析、局部替换与富文本序列化，
并使用模拟 CLI 验证保存失败、账号隔离和版本检查；`make test TEST=feishu-component`
验证组件签名向量、临时回环宿主与开发版入口闸。两者都不写真实飞书文档。
`python3 Tools/render-feishu-preview.py` 生成真实生产渲染表面的合成文档截图，
覆盖 1200 / 760pt 与浅色 / 深色。仅控件外壳和偏好来源为隔离夹具。
组件 SDK 加载、鉴权、图片与窗口缩放须在正式版用已授权的自建应用验证；
原生表格的行列增删、尺寸往返与未修改单元格 HTML 保留由回归覆盖，
真实飞书权限、私有嵌入资源，以及服务器对列宽、行高和全文替换的保留行为仍需端到端验证。
不读取真实云文档，不请求系统权限。

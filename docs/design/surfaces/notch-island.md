# 多屏灵动岛

模式：Operate。AI 编程者在 MacBook 与外接屏之间工作，入口随屏幕可达，提醒每次只在一处出现，不打断当前焦点。沿用已有纯黑灵动岛、系统圆体、身份色与会话／用量内容。

## 形态

- 硬件刘海：保留两翼与融入顶边的轮廓，真实刘海区域留空。
- 无刘海屏幕：菜单栏下方 8pt 的独立黑色胶囊；154×28pt 的收起态直接排列 Agent／运行数与今日用量。关闭读数后保留 42×28pt 的省略号入口。
- 外接提醒：380×82pt，四角 22pt；外接展开：520×320pt，四角 26pt。沿用同一会话宫格、滚动与用量卡。
- 不增加装饰模糊、阴影或持续 SwiftUI 动画；胶囊采用既有 9% 白色轮廓，读数为 92% 白色。

## 交互

- 所有屏幕默认有入口；支持仅内置屏／指定屏幕。显示器 UUID 存在当前 bundle 的 UserDefaults；暂时断开时保留选择。
- 悬停 120ms 展开，外接胶囊也可直接点击。从另一处展开详情切入，需停留 250ms；同一时刻只有一处展开或提醒。
- 鼠标按住、拖动窗口或图表时不切屏、不自动收起正在操作的详情。提醒出现后固定在原屏，新的提醒在同处替换；主动打开另一入口才收起旧提醒。
- 拔掉提醒屏幕时将原提醒及剩余截止时间交给可用屏，不重复事件、不重新计时。几何变化收起详情；镜像只保留一个入口，上下屏边界的热区不会穿入邻屏。
- 透明圆角与面板剩余透明区穿透点击；收起的硬件刘海入口保持原来的鼠标穿透，外接胶囊仅捕获轮廓内点击。

## 性能与边界

所有面板共用一个 IslandLiveModel、数据订阅和周期用量刷新。只有一对鼠标监听，收起态没有离开计时器；打开时只有一个 10Hz 检查计时器。命中路径按形态缓存，普通鼠标移动不创建视图或查询数据，不重复设置窗口捕获标志。

详细规则与验证命令见 [灵动岛设计](../10-notch-island.md)。合成多屏回归直接驱动生产控制器；系统输入、存储、通知和触觉使用替身。真实拔插、合盖、混合 DPI、全屏 Space、VoiceOver 实操不能从此夹具推断。

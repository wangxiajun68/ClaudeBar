# 多屏灵动岛

模式：Operate。AI 编程者在 MacBook 与外接屏之间工作，入口随屏幕可达，提醒每次只在一处出现。共用数据与操作，按屏幕是否有硬件刘海选择呈现。

## 形态

- 硬件刘海：保留纯黑两翼、顶边轮廓、双列会话与用量图，真实刘海区域留空。
- 无刘海屏幕：菜单栏下方 8pt 的石墨灰状态条，232×32pt、12pt 连续圆角。显示运行数、会话数及待确认数量；无任务时显示空闲。关闭读数后保留 42×32pt 的入口。
- 悬停摘要：280×64pt，显示优先会话的名称与当前活动；无会话时提供查看用量入口。
- 外接提醒：360×72pt 的单行布局，保留完成／待确认／额度重置及对应操作，不播放轮廓扫光。
- 外接详情：360×300pt、16pt 连续圆角，48pt 标题区、三行 56pt 会话的滚动区、32pt 提示区及 52pt 用量摘要。沿用模型的待确认优先、运行中其次排序。项目名和活动截断；状态与跳转箭头固定对齐。
- 今日 Token 与估算费用使用中性色、小字号、等宽数字；沿用分列／换算与未计价提示，分列时同时展示两种货币。完整趋势与费用详情在工作台。
- 外接形态使用静态阴影、细轮廓及 98% 不透明底，不使用背景模糊、持续旋转或数字滚动。

## 交互

- 所有屏幕默认有入口；支持仅内置屏／指定屏幕。显示器 UUID 存在当前 bundle 的 UserDefaults；暂时断开时保留选择。
- 刘海屏保持悬停 120ms 展开与离开 250ms 收起。无刘海屏悬停 300ms 仅显示摘要，离开后收起。
- 点击外接状态条、摘要或提醒打开详情；鼠标移出不会关闭，也不会因路过另一屏入口切换。点击外部、关闭按钮或 Esc 收起。只有明确点击打开的外接详情可取得键盘焦点；预览和提醒不抢焦点，不监听全局键盘。
- 外接展开与收起使用 220ms ease-out；系统减少动态效果开启时禁用控制器过渡动画。
- 同一时刻只有一处展开或提醒。鼠标按住、拖动窗口或图表时不自动切屏。提醒出现后固定在原屏，新的提醒在同处替换；主动打开另一入口才收起旧提醒。
- 拔掉提醒屏幕时将原提醒及剩余截止时间交给可用屏，不重复事件、不重新计时。几何变化收起详情；镜像只保留一个入口，上下屏边界的热区不会穿入邻屏。
- 透明圆角与面板剩余透明区穿透点击；收起的硬件刘海入口保持鼠标穿透。

## 性能与边界

所有面板共用一个 IslandLiveModel、数据订阅和周期用量刷新。只有一对鼠标监听，收起态与点击打开的外接详情没有关闭轮询；悬停预览、自动收起的刘海详情、短提醒共用一个 10Hz 检查计时器。命中路径按形态缓存，普通鼠标移动不创建视图或查询数据，不重复设置窗口捕获标志。窗口和宿主画布固定尺寸，动画不调整 NSWindow 大小；外接会话采用 LazyVStack，无逐行时间刷新。

`Tools/render-island-preview.py` 用生产视图和合成数据输出刘海／无刘海屏的浅深背景预览，覆盖收起、预览、提醒、详情、空列表、长标题与双币费用。`make test TEST=island-display` 驱动生产控制器，覆盖延迟悬停、点击保持、外部点击、Esc、跨屏、断开与计时器释放。系统输入、存储、通知和触觉使用替身。

真实拔插、合盖、混合 DPI、全屏 Space、VoiceOver 与实际键盘焦点恢复仍需人工实操；夹具和编译不能替代这些验证。

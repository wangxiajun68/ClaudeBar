# 多屏灵动岛

模式：Operate。AI 编程者在 MacBook 与外接屏之间工作，入口随屏幕可达，提醒每次只在一处出现。共用数据与操作，按屏幕是否有硬件刘海选择呈现。

## 形态

- 硬件刘海：保留纯黑两翼、顶边轮廓、双列会话与用量图，真实刘海区域留空。
- 无刘海屏幕采用用户选定的 **A · Focus deck**：[批准稿](../../../.impeccable/mocks/external-console/a-focus.png)。原生绘制银白边缘、内嵌深靛蓝显示面和银色底沿；不使用概念图作为 UI 贴图。
- 收起 440×48pt，展开 440×212pt，均为 16pt 连续圆角。菜单栏下方 8pt；上下态共享同一个 48pt 标题栏，不横向跳动。关闭读数时入口为 44×48pt。
- 标题栏由工作台入口、前三个真实会话标识、全部会话菜单、当前会话状态与待处理入口组成。相同客户端的多个会话通过项目名区分；选中会话按 ID 保持，消失时退回优先会话。待确认计数可直接定位需要处理的会话。
- 取消悬停摘要中间态；悬停直接展示完整详情。外接提醒 440×72pt，不抢键盘焦点、不播放扫光。
- 展开后 95pt 主舞台突出项目与实际活动，28pt 信息行显示真实模型和上下文占用（未知显示 —），提供返回原会话的动作。待确认时保留项目标题，活动与操作使用暖橙；应用本身不代用户批准工具请求。标题过长在中间截断，悬停可读完整内容。
- 40pt 银色底沿展示今日 Token 和估算费用。支持分列／换算与未计价提示，两种货币同时保留；完整趋势在工作台。
- 色彩：显示面 #0D1728—#18263D，次要文字 #ACBED8，选中蓝 #A0BCDF，运行绿 #98CCBA，确认橙 #FFAE62，外沿 #DCE4EE。静态方向性明暗提供浅层次，无背景模糊、持续发光、逐帧材质、持续旋转和数字滚动。

## 交互

- 所有屏幕默认有入口；支持仅内置屏／指定屏幕。显示器 UUID 存在当前 bundle 的 UserDefaults；暂时断开时保留选择。
- 刘海屏保持悬停 120ms 展开与离开 250ms 收起。无刘海屏悬停 160ms 直接展开，离开 250ms 收起；短暂经过不展开。原生菜单跟踪时暂停离开关闭。
- 悬停即可操作全部详情；点击入口或提醒保留为辅助功能补充路径；鼠标移出不会关闭，也不会因路过另一屏入口切换。点击外部、关闭按钮或 Esc 收起。只有明确点击打开的外接详情可取得键盘焦点；悬停展开和提醒不抢焦点，不监听全局键盘。
- 外接展开与收起使用 220ms ease-out；系统减少动态效果开启时禁用控制器过渡动画。
- 同一时刻只有一处展开或提醒。鼠标按住、拖动窗口或图表时不自动切屏。提醒出现后固定在原屏，新的提醒在同处替换；主动打开另一入口才收起旧提醒。
- 拔掉提醒屏幕时将原提醒及剩余截止时间交给可用屏，不重复事件、不重新计时。几何变化收起详情；镜像只保留一个入口，上下屏边界的热区不会穿入邻屏。
- 透明圆角与面板剩余透明区穿透点击；收起的硬件刘海入口保持鼠标穿透。

## 性能与边界

所有面板共用一个 IslandLiveModel、数据订阅和周期用量刷新。只有一对鼠标监听，收起态与点击打开的外接详情没有关闭轮询；悬停展开、自动收起的刘海详情、短提醒共用一个 10Hz 检查计时器。命中路径按形态缓存，普通鼠标移动不创建视图或查询数据，不重复设置窗口捕获标志。窗口和宿主画布固定尺寸，动画不调整 NSWindow 大小；外接面板仅绘制三个静态会话标识和一个选中会话，全部会话通过原生菜单按需呈现，无逐行时间刷新。

`Tools/render-island-preview.py` 用生产视图和合成数据输出刘海／无刘海屏的浅深背景预览，覆盖收起、提醒、详情、空会话、长标题与双币费用。`make test TEST=island-display` 驱动生产控制器，覆盖延迟悬停、点击保持、外部点击、Esc、跨屏、断开与计时器释放。系统输入、存储、通知和触觉使用替身。

真实拔插、合盖、混合 DPI、全屏 Space、VoiceOver 与实际键盘焦点恢复仍需人工实操；夹具和编译不能替代这些验证。

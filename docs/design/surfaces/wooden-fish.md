# 桌面木鱼

原生 macOS SwiftUI / AppKit 桌面挂件。精致感来自暖木色块、克制线条与直接的器物操作。此视觉语言仅属于木鱼，不改变 ClaudeBar 的全局卡片、排版或导航系统。使用说明见 [桌面木鱼](../../WOODEN_FISH.md)。

## 设计契约

- **THESIS**：把一件可敲、可移动的小器物放在桌面上。
- **OWN-WORLD**：暖杏色不对称共鸣腔、可可色细轮廓、一笔连接开口的内卷刻槽、暖木色敲棒。
- **STORY**：点击松开后敲击，直接拖动移动；全部配置留在应用设置。
- **FIRST VIEWPORT**：静置只出现器物与敲棒，没有可见按钮或菜单；计数按需出现。
- **FORM**：透明背景、共享形状命中、无空闲动画；反馈容量有界。

## 视觉与空间

本体为四段贝塞尔曲线组成的不对称共鸣腔，并非规则椭圆。基准边界仍为 178 × (178 / φ)，φ = (1 + √5) / 2；两个轴使用同一投影倍率。轮廓宽 6，连续刻槽宽 7，短高光弧宽 3，底弧宽 8，敲棒宽 10；均采用圆端点／圆转角。本体的连续内卷刻槽取代旧版独立眼睛与开口，让器物呈现雕刻结构。

| 部位 | 浅色配色 | 深色配色 |
| --- | --- | --- |
| 本体填色 | 暖杏 `#F5CC91` | 蜜木 `#D99558` |
| 本体轮廓与棒柄 | 可可 `#764426` | 浅奶金 `#FFE1AA` |
| 高光弧与底弧 | 木金 `#B57B40` | 浅杏 `#FCE0AD` |
| 连续刻槽 | 深木 `#884725` | 深可可 `#69361F` |
| 敲棒头 | 暖木 `#DB9B52` | 浅木 `#F5D09B` |

器物采用不透明纯色填充，无渐变、纹理或背景卡片；窗口自身无阴影。反差细边沿相同路径绘制，比前景线宽 1.8；浅色为 90% 的 `#F6FCFA`，深色为 90% 的 `#101D24`，辅助不同壁纸上的辨识。敲棒 Canvas 扩展绘制边界后居中，保护圆头与柄端免于裁切。

`WoodenFishSize.panelSize` 宽为 `260 × scale`，高为 `78 + 200 × scale`。小巧／标准／大号缩放 0.60／0.72／0.88，对应 156×198、187.2×222、228.8×254pt。上方 36pt 为透明反馈留白，中间器物按 240×200pt 坐标缩放，下方计数高 36pt。占位矩形不是可见表面。

## 状态与交互

| 状态 | 可见内容与行为 |
| --- | --- |
| 静置 | 暖木器物、敲棒与短底弧，无循环动画。 |
| 悬停 | 形状命中后器物轻微提亮，显示计数。 |
| 按下／松开 | 按下有短促压缩；移动未满 5pt 且松开仍命中器物才敲击。 |
| 拖动 | 位移达到 5pt 即转为原生拖动，取消敲击；位置保存。Option 拖动仍兼容。 |
| 敲击反馈 | 本体回弹、敲棒落击、独立浮字；计数区展示连击或彩蛋。 |
| 自动敲击 | 计数持续可见，按设置中的 0.5／1／2／3 秒节奏运行。 |

**器物即操作目标。** 不显示按钮栏、右键菜单或隐藏菜单入口。音效、音量、自动启停、节奏、大小、清空记录与隐藏均由设置管理；清空需确认。辅助功能保留可激活的敲击语义与操作提示，焦点内空格敲击、Escape 暂停并复位连击，不注册全局快捷键。

计数为非交互的两行读数：今日数字 13pt 半粗圆体、等宽数字；标题及次行 10pt。白色主文字和 `#FFE0A6` 次行位于 94% 不透明的 `#29221C` 圆角背景，圆角 10pt，左右内边距 10pt。次行按反馈显示彩蛋、连击、音效不可用、自动节奏或累计计数。计数在悬停、自动敲击或尚有反馈时可见；不捕获鼠标。

## 命中与负载边界

`WoodenFishGeometry` 的本体、敲棒及底弧共享绘图与捕获几何。命中包括实心内部及描边；鼠标坐标先还原缩放，再逆转敲棒静置旋转与位移。透明上边距、外围以及计数区均点击穿透；动画不扩大命中范围。失焦、Escape 或拖动取消待完成的点击，拖动不计数。

命中用的填充与描边 `CGPath` 缓存为静态不可变值，鼠标移动不重复生成路径。窗口外先做矩形排除，不进入路径命中；悬停状态只有发生变化才发布。反馈池最多四组，超出删除最早一组，同帧合并事件也只补齐最近四次；每组动画 1.35 秒、约 1.42 秒清除。没有持续空闲动画。这些是实现约束，CPU、内存与能耗效果仍须实际采样，不能据此宣称零负载。

浮字为透明的「功德 +1」，原生 10pt 半粗圆体与 18pt 粗圆体斜字，间距 3pt，沿字形使用细反差边；+1 下方的短弧逐渐收短。普通浮字使用暖棕／浅杏，八连击起或彩蛋转暖金。每次拥有稳定且独立的起点、方向、曲率和速度，新反馈不重排旧轨迹。普通点击与自动敲击没有粒子，只有手动连击达到八时每组显示三颗 3pt 暖色粒子，因此粒子总量上限十二颗。反馈层不捕获鼠标，也不进入辅助功能树。

Reduce Motion 取消本体、敲棒与按压变换、粒子和浮字弧线，仅最新浮字在固定位置渐隐。计数、音效与彩蛋文案保留。

## 手动节奏与生命周期

相邻手动敲击间隔不超过 0.55 秒形成连击。八／十六／三十二连击分别显示「8 连击 · 进入心流」「There is no spoon.」「烦恼 Cache Miss」。累计恰好到达 108／1024／4096 时分别显示「108 · 心静如水」「1024 · Hello, world.」「4096 · Inner peace」，同次累计里程碑优先；每种彩蛋有八秒冷却。

「今日开敲」是本次启动中当天第一次手动敲击。自动敲击不消耗手动首击、不形成连击、不触发彩蛋。每次只增加一份功德，不改变真实模型 Token 用量。今日计数随本机日期重置；自动敲击不持久化，隐藏、休眠、屏幕休眠、退出或性能模式停止计时器和音效并复位连击，恢复显示不自动恢复敲击。

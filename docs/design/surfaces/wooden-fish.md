# 桌面木鱼

原生 macOS SwiftUI / AppKit 桌面挂件。设计主体是直接悬浮的紧凑实心彩色木鱼与敲棒。本体为不透明玉绿填色，敲棒头与柄分别填满暖金和青碧，外围保留透明桌面背景。现代、简洁的轮廓只属于这一挂件，不改变应用的通用卡片语言。使用说明见 [桌面木鱼](../../WOODEN_FISH.md)。

## 设计契约

- **THESIS**：器物本身透明悬浮在桌面。
- **OWN-WORLD**：实心玉绿本体、圆润青碧粗轮廓与黄金比例，珊瑚色开口、实心暖金圆棒头。
- **STORY**：点击敲击，快速手动敲击形成独立词云与连击彩蛋；右键打开原生菜单。
- **FIRST VIEWPORT**：静置只显示紧凑木鱼与敲棒；仅计数按需出现。
- **FORM**：按器物形状捕获鼠标，无空闲装饰动画。

## 视觉与空间

木鱼以真正的椭圆本体、内收开口、内部弧线与实心眼辨识器物。黄金比例 `φ = (1 + √5) / 2` 约为 1.618；包含反差描边的本体可见边界为 178 × (178 / φ)，绘图在两个轴使用同一投影倍率，椭圆比例不会被画布高度拉伸。眼睛中心落在可见边界横向 1 / φ、纵向 1 / φ² 的位置。棒头使用直径 24 的圆；包含描边的棒头直径与棒柄可见厚度之比为 φ，底部弧线可见宽度为本体宽度的 1 / φ。这些数值属于基准绘图坐标，随器物尺寸缩放。

本体主描边为 16，开口和敲棒为 10，内弧和底部弧线为 8，实心眼描边为 5.2；圆端点与圆转角统一圆润形态。粗线之间保留清晰间隔，器物采用实心纯色，无材质纹理。

| 部位 | 浅色配色 | 深色配色 |
| --- | --- | --- |
| 本体填色 | 玉绿 `#BDDCD1` | 深玉绿 `#245D60` |
| 本体轮廓与敲棒柄 | 青碧 `#23828C` | 亮青碧 `#68CDC7` |
| 内弧与底部弧线 | 灰绿 `#478C82` | 浅绿 `#9ECFC3` |
| 开口与实心眼 | 珊瑚 `#B85B49` | 浅珊瑚 `#F29B86` |
| 敲棒头 | 暖金 `#AD7A32` | 浅金 `#E4BF77` |

本体由冷色统一，珊瑚色标出开口，暖金明确敲击部件；颜色各自依附形状，不靠颜色区分操作状态。玉绿填色上的主轮廓与开口对比度分别为 3.08:1、3.09:1，深玉绿上的对应对比度为 3.97:1、3.49:1。内弧是无状态含义的装饰曲线；任意桌面壁纸仍依赖反差描边辅助辨识。

每条路径先绘制基准宽度比前景多 1.8 的窄反差描边，再绘制前景线。反差描边浅色为 90% 不透明度的 `#F6FCFA`，深色为 90% 不透明度的 `#101D24`，沿同一条路径提高壁纸上的辨识度；本体、眼、敲棒头与柄使用完全不透明的单色填充，无渐变、纹理、阴影或背景卡片，窗口自身无阴影。敲棒 Canvas 在四周预留半个总描边宽度向上取整的绘制空间，再居中回原 74×23pt 布局，抵消绘图平移，避免粗线圆头和柄端被裁切；旋转中心和共享命中坐标保持一致。

占位来自 `WoodenFishSize.panelSize`：宽为 `260 × scale`，高为 `70 + 200 × scale`。小巧／标准／大号的器物缩放为 0.60／0.72／0.88，对应 156×190、187.2×214、228.8×246pt。标准本体比原标准版线性缩小 28%，绘制面积约减半；文字不随尺寸选项缩小。顶部透明留白高 36pt，用于词云空间，不包含按钮或鼠标捕获，中间敲击区按 240×200pt 的器物坐标缩放，下方计数区始终高 28pt。占位矩形不是可见表面。挂件跨桌面空间显示，可伴随全屏；按住 Option 拖动器物的位置保存，屏幕变化后夹回可见范围。

## 状态与控件

| 状态 | 可见内容与行为 |
| --- | --- |
| 静置 | 只显示实心彩色木鱼、实心敲棒与底部粗弧，无常驻装饰动画。 |
| 悬停 | 指针进入挂件占位范围后，器物轻微提亮，只显示下方今日／累计功德；离开后隐藏，无持续反馈时回到静置。 |
| 手动连击／彩蛋 | 下方胶囊暂时显示连击与今日计数，或金色彩蛋文案；反馈到期后恢复。 |
| 自动敲击 | 计数持续可见，右键菜单可暂停；按选定的 0.5、1、2、3 秒节奏敲击。 |

器物不显示任何按钮栏。静音、自动启停、节奏、大小、记录清空与隐藏均由右键原生菜单提供，清空记录仍需确认。悬停只提亮器物并显示计数；按住 Option（⌥）左键拖动器物时，木鱼窗口调用原生拖动并保存位置，正常点击仍敲击。按压器物缩至 98%。计数使用原生 11pt 系统圆体与等宽数字、72% 不透明度黑色胶囊，长数字按可用宽度收缩；隐藏后可从设置重新开启。

点击木鱼或敲棒的实心本体与轮廓、底部粗弧均可敲击，获得键盘焦点后空格也可敲击，Esc 暂停自动敲击并复位连击。Esc 只由木鱼窗口处理，不注册全局快捷键。一次敲击增加今日和累计计数，并在未静音且音量大于零时播放短木质音效。音效不可用时计数仍有效，计数旁显示提示图标。今日记录按本机日期重置；自动敲击仅属于本次会话，隐藏、休眠、屏幕休眠、退出或性能模式均停止，唤醒及重新显示不自行恢复。

## 形状、命中与反馈

`WoodenFishGeometry` 共享本体、底部粗弧和敲棒路径，绘图与桌面鼠标捕获使用同一几何。本体和敲棒使用与绘图相同的实心路径，内部与轮廓均是可敲击的完整目标；命中还包含其窄反差描边与底部粗弧。上方 36pt 留白不捕获鼠标；器物命中在留白之下还原缩放坐标，再逆转敲棒实际绘图的位移和静置旋转。器物外围透明区域、上方留白与计数胶囊均可点击穿透，不因悬停而捕获整个矩形。敲击反馈保持静态命中轮廓，不移动窗口或放大捕获范围。

反馈只由敲击触发：本体轻微压缩、偏转后回弹（约 0.35 秒），敲棒抬起、落击、回弹并归位（约 0.46 秒）。每次从敲击处向上发散六颗金色／青色／紫色小菱形（`#FFD58F`／`#8CEAFF`／`#E3B8FF`），并生成独立的一条「Token +1」。文字直接透明悬浮，不使用黑底、胶囊或容器内边距。Token 使用原生 10pt 半粗圆体，+1 使用原生 18pt 粗圆体斜字，基线对齐并留 3pt 间距；+1 下方一笔 20×3pt 的细弧随动画收短。浅色主题的 +1 使用青碧 #1D7C86／暖金 #A8652C，小字使用更深的 #18565D／#824923；深色主题为浅青 #91EEE2／浅金 #FFE1A3。四向 0.65pt 反差细描边只沿字形，提高桌面壁纸上的辨识度，不形成背景面。八连击起或彩蛋触发时转为暖金色。菱形保持原生 3pt。

快速敲击最多保留八条透明浮字，不按列、层或固定位置排列。每次敲击根据自身 ID 获得稳定且不同的起点、扇形方向、射程、曲率、上升速度、大小与转角；低差异角度分布让连续敲击向左右和上方散开。新反馈不会重排正在飞行的旧文字，已生成的轨迹不随视图刷新变化。

浮字以减速弧线飞离器物，轻弹展开，最多偏转约 14°；不同尺寸按原生文字边界计算横向射程，保留顶部与计数区的安全间距。每次敲击保留自己的词条，同一帧合并的敲击事件按 ID 补齐最近八次。单组反馈动画 1.35 秒，约 1.42 秒清除；超过八组时移除最早一组，到期自动清除，不启动空闲循环。反馈层不接收点击，也不进入辅助功能树，不扩大窗口或鼠标捕获范围。

开启 Reduce Motion 后不显示粒子，取消本体、敲棒与按压的缩放、旋转及位移，关闭浮字弧线；仅保留最新一条固定位置的「Token +1」淡入淡出。计数、音效与彩蛋文案仍可用。器物提供敲击辅助功能名称，以及 Option 拖动和右键选项提示。

## 手动节奏与彩蛋

相邻手动敲击间隔不超过 0.55 秒形成连击，间隔更长则从一重新开始。八连击显示「8 连击 · 进入心流」，十六连击显示「There is no spoon.」，三十二连击显示「烦恼 Cache Miss」。手动敲击使累计恰好到达 108、1024、4096 时，分别显示「108 · 心静如水」「1024 · Hello, world.」「4096 · Inner peace」，累计里程碑优先于同次连击提示；每一种彩蛋有独立的八秒冷却。

「今日开敲」指本次启动中当天第一次手动敲击，属于会话内节奏状态，不持久化。自动敲击不会消耗当天手动首击，不形成连击，也不触发彩蛋；它仍保留普通反馈与一次加一的计数。暂停、隐藏、休眠、屏幕休眠与性能模式复位连击链，重新显示或唤醒不会恢复自动敲击。所有反馈都不增加额外功德或音效，「Token +1」不改变真实模型 Token 用量。

# 桌面木鱼

模式：Experience。用户目标是精细、轻巧的桌面解压玩具，桌面仅有点击和拖动，不展示任何按钮、工具栏或右键菜单。应用的其他界面保持现有设计系统。

## 设计契约

- 器物优先：非对称圆润共鸣体、连续回纹开口与木槌，透明背景。
- 暖杏／可可的局部配色；深色主题为烤杏色本体与浅奶油轮廓。
- 点击立即进入按压状态，松手计数与落击；5pt 移动阈值区分拖动，释放取消后不误加功德。
- 悬停或敲击才显示轻量只读记录；计数不替代器物，不获得点击。
- 无静置动效。节奏、音效、隐藏和记录操作属于设置页。

## 交互与性能边界

参考 [使用与验证](../../WOODEN_FISH.md)。命中复用共享路径，透明边角及计数穿透。左键按下后只显示按压反馈，松手且没有越过 5pt 阈值才敲击；拖动走 AppKit 原生窗口移动。Esc 和失焦取消待提交敲击。所有配置统一放在 SettingsView，清空需确认。

单个 Canvas 合并器物、木槌、浮字与粒子。两组双行反馈完整播放；被新敲击挤出的旧组保留位置与轨迹，以 180ms 平滑淡出，尾迹上限 24 组。每组八连击起才有三颗粒子，粒子同步淡出。异步刷新任务只在反馈存活时存在，以 16.67ms 的绝对截止时间调度，目标 60fps；发生延迟时跳过错过的帧；新敲击添加从零开始的共鸣响应，保留已有回弹，最后敲击后 1.42 秒结束。减少动态效果取消器物变形、粒子及文字运动，只留下最新双行浮字及旧组尾迹的定点淡出。按压用 80ms 缓出，松手从当前形变连续恢复。首次显示提前测量中英文字形；声音开启时，波形与播放器提前在专用串行队列准备，播放也在后台。静音、隐藏、休眠及退出使旧播放请求与回调失效。音效不会因彩蛋重复播放。

## 证据范围

预览来自生产 SwiftUI／AppKit 视图，覆盖三档尺寸、两种主题、自动状态与快速连敲。回归与 CPU 测量使用临时偏好和独立静音夹具。构建／回归结果以当前交付记录为准；不把静音夹具或编译通过描述成真人拖动、真实音频或 VPN 系统集成验证。

本次把三档缩放从 0.60 / 0.72 / 0.88 改为 0.36 / 0.46 / 0.56；标准本体约 90pt 宽，线性缩小约 36%，可见本体面积缩小约 59%。浮字保持原生尺寸，轨迹的水平边界、顶部留白和计数区间距随更小的画布重新约束。

高帧率验证通过独立静音可见视图夹具，报告实际绘制频率、帧间隔 P95、超过 25ms 的间隔和 CPU 时间；绘制频率不等同于屏幕实际呈现帧率，结果只代表本机夹具。历史 34ms 刷新版本的 CPU 数字不用于描述本次 60fps 版本。

当前淡出与预热版本在标准档、每秒 12 次敲击、持续三秒的静音可见夹具中实测约 59.99 次绘制／秒，帧间隔 P95 约 17.81ms，无超过 25ms 的间隔；首次反馈重绘约 1.85ms，活跃阶段进程 CPU 时间约 0.382 秒，停止反馈后的三秒约 0.00028 秒 CPU 且无绘制。这是本机绘制及 CPU 数据，未测量真实音频输出延迟或屏幕呈现帧率。

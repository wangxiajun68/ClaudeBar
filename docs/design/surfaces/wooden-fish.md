# 桌面木鱼

原生 macOS SwiftUI / AppKit 桌面挂件。设计主体是直接悬浮的矢量木鱼、敲棒和玉绿色垫子；透明背景保留桌面，不套应用的通用卡片、边框、内环或面板阴影。使用说明见 [桌面木鱼](../../WOODEN_FISH.md)。

## 视觉与空间

木鱼以曲线轮廓、裁剪到本体内的六条疏密曲纹与两条浅木节呈现木质体积。暖木渐变从浅琥珀（`#DDB378`）经蜂蜜棕（`#BE864C`）、深棕（`#925529`）到木色暗部（`#56311F`），局部柔和径向高光与细轮廓保留圆润体积；口部是细雕刻槽，眼睛有浅色细环。垫子改为薄椭圆，从灰玉绿（`#819889`）经深绿（`#4A6859`）到暗绿（`#263E34`），带轻微折痕和细虚线缝边。敲棒有弧形高光和细柄高光。两种应用配色下本体保持这套材质色，低透明度落地椭圆与局部投影只服务于器物体积；窗口自身无阴影。

占位来自 `WoodenFishSize.panelSize`：宽为 `260 × scale`，高为 `70 + 200 × scale`。小巧／标准／大号的器物缩放为 0.60／0.72／0.88，对应 156×190、187.2×214、228.8×246pt。标准本体比原标准版线性缩小 28%，绘制面积约减半；工具与文字不随尺寸选项缩小。顶部工具行始终高 36pt，中间敲击区按 240×200pt 的器物坐标缩放，下方计数区始终高 28pt。占位矩形不是可见表面。挂件跨桌面空间显示，可伴随全屏；拖动位置保存，屏幕变化后夹回可见范围。

## 状态与控件

| 状态 | 可见内容与行为 |
| --- | --- |
| 静置 | 只显示矢量木鱼、敲棒和垫子，无常驻装饰动画。 |
| 悬停 | 指针进入挂件占位范围后，显示上方五个独立工具和下方今日／累计功德；离开后隐藏。 |
| 自动敲击 | 工具和计数持续可见，自动按钮显示绿色暂停图标；按选定的 0.5、1、2、3 秒节奏敲击。 |

五个工具依次为拖动、静音、自动敲击、更多、隐藏。每个工具是原生 26pt 黑色半透明圆底（72% 不透明度）配 12pt 白色图标，圆间距 4pt；工具行总宽 146pt，在最小 156pt 占位内仍完整适配，它们没有共同面板。计数以原生 11pt 系统圆体、等宽数字显示在同样黑底的胶囊上，长数字按可用宽度收缩。更多保留原生菜单行为，外层自绘同族圆底和省略号；菜单选择节奏与大小，清空记录需确认。隐藏后可从设置重新开启。

点击木鱼、垫子或敲棒敲击，获得键盘焦点后空格也可敲击。一次敲击增加今日和累计计数，并在未静音且音量大于零时播放短木质音效。音效不可用时计数仍有效，计数旁显示提示图标。今日记录按本机日期重置；自动敲击仅属于本次会话，隐藏、休眠、屏幕休眠、退出或性能模式均停止，唤醒及重新显示不自行恢复。

## 形状、命中与反馈

`WoodenFishGeometry` 共享本体、垫子、垫沿和敲棒路径，绘图与桌面鼠标捕获使用同一几何。工具以原生坐标捕获各自 26pt 圆形；器物命中在固定工具行之下还原缩放坐标，再逆转敲棒实际绘图的位移和静置旋转。透明边距、工具间隙、落地阴影与计数胶囊均可点击穿透，不因悬停而捕获整个矩形。敲击反馈保持静态命中轮廓，不移动窗口或放大捕获范围。

反馈只由敲击触发：本体轻微压缩、偏转后回弹（约 0.35 秒），敲棒抬起、落击、回弹并归位（约 0.46 秒）。每次从敲击处向上发散六颗金色／青色／紫色小菱形（`#FFD58F`／`#8CEAFF`／`#E3B8FF`），并显示一条浅青色「Token +1」（`#8CEAFF`）。文字以原生 12pt 半粗系统圆体和黑色半透明胶囊绘制；菱形基准尺寸保持原生 3pt。只有器物和粒子轨迹随大小选项缩放。「Token +1」只显示最近一次敲击的一条，沿中间轨迹上移淡出；新敲击立即取代旧文字，快速敲击时文字不会互相覆盖。发散、轻微缩放／旋转与淡出约 0.85 秒完成，每组约 0.92 秒清除。「Token +1」是敲击趣味反馈，不改变真实模型 Token 用量，每次敲击照常增加今日与累计计数。

六颗彩色粒子可随快敲叠加，`WoodenFishBurstPool` 最多保留八组，超出时移除最早一组；到期自动清除，不启动空闲循环。文字用 `showsWord: id == pool.ids.last` 限定为最新一条。反馈层不接收点击，也不进入辅助功能树。开启 Reduce Motion 后停用器物与粒子的位移、缩放和旋转，仅最新一条静止「Token +1」淡入淡出；计数和音效仍保留。工具具备独立辅助功能名称，隐藏时同时退出命中与辅助功能树。

## 验证

`Tools/render-wooden-fish-preview.py` 从生产视图生成三档尺寸、两种配色的透明预览；本轮已核对缩小后的 `regular-light.png` 与 `small-dark-hover.png`。`python3 Tools/render-wooden-fish-preview.py --motion` 捕获实际生产视图的单次与连续敲击动画帧。`make test TEST=wooden-fish` 验证计数、波形、位置、共享鼠标命中、粒子运动与池容量逻辑；实际控制器的静音夹具验证入口见使用说明。预览与夹具不等同于真实桌面音频输出验证。

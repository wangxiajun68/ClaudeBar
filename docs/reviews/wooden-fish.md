# 桌面木鱼改版自查

范围：原生桌面木鱼；按用户最终要求只保留点击与拖动，不展示按钮或右键菜单。独立复核子代理因额度耗尽未能执行，下列记录为本轮自查，不是独立审查。

## 视觉证据

生产视图生成小巧／标准／大号、浅色／深色预览，以及连敲、自动与减少动态效果状态。最终绘制面扩至 260pt，保留器物 10pt 横向起点，修复 Canvas 合并后木槌圆头被裁切的问题。外形、文字与透明背景正常；完整奖励为两组双行文字，旧组另有短暂淡出尾迹，计数为只读。

## 交互与可访问性

生产控制器静音夹具覆盖按下不计数、释放只计一次、重复释放不计数、超阈值释放不误敲、自动计时器更换、窗口 Escape、隐藏与性能模式释放。五个原生点的拖动阈值另有直接生产状态机回归。木鱼保留按钮语义、功德朗读值及键盘辅助操作；桌面上没有可见按钮。设置保留音效、自动敲击、节奏、大小、清空确认与显示开关。

## 性能证据

早期版本使用单个 Canvas 与 34ms 可取消任务；后续 60fps 与连续淡出版本的证据见下方记录。早期任务仅在反馈存活时运行，最近敲击结束后约 1.42 秒停止刷新。共享命中路径缓存；鼠标在窗口外提前返回，不发布重复悬停状态。

本机可见静音生产视图夹具，在每秒十二次敲击的三秒阶段，进程 CPU 时间由约 3.05 秒降到约 0.29～0.44 秒；三秒静置约 0.001 秒，停止反馈后的三秒约 0.0003 秒。该数字不是整个应用的 CPU 占用承诺。

## 回归范围

全量 102 组回归通过；最后绘制和取消行为修改另外通过木鱼专项。独立静音控制器夹具通过。开发和正式包校验结果由本轮构建日志提供，不能从视图预览推断。

## 结论与限制

本轮自查未发现阻止交付的木鱼视图问题。真人桌面拖动、真实音频输出与 VoiceOver 实操未验证；未执行正式版安装，也未验证 VPN 或硬件系统集成。

## 2026-10-12：紧凑尺寸、双行奖励与 60fps

三档缩放改为 0.36 / 0.46 / 0.56，标准本体约 90pt 宽，比上一版线性缩小约 36%。每次敲击同时显示「功德 +1」与「Token +1」，最多展示两组双行奖励；Token 只属于趣味反馈，不改变真实用量。两行文字在更小的画布中保留原生字号，顶部透明留白纳入同一 Canvas，避免浮字进入留白时被裁切。

刷新使用 16.67ms 的绝对截止时间，目标 60fps。错过的帧直接跳过，不积累追赶工作；每帧复用已解析的两种颜色奖励文字，静置不启动刷新任务。

最终标准档静音可见视图夹具，每秒 12 次敲击、持续三秒：实际绘制约 59.98 次／秒，帧间隔 P95 为 17.80ms，无超过 25ms 的间隔；活跃阶段约消耗 0.423 秒进程 CPU 时间。反馈结束后的三秒无绘制，CPU 时间约 0.00032 秒。此数值为本机夹具绘制频率，不能等同于任意机器、任意负载下的屏幕呈现保证。

三档尺寸与两种主题、双行奖励、快敲及减少动态效果预览检查通过；点击／拖动状态机、静音生产控制器夹具与木鱼专项通过。全量 102 组回归通过；dev 和 release 的包身份、Widget、URL scheme、entitlements 与签名检查通过。未安装正式版，真人拖动和真实音频输出没有新增验证。

60fps 预览视频：`.build/wooden-fish-preview/wooden-fish-compact-60fps.mp4`，240×340px，共 360 帧。

## 2026-10-12：连续淡出与首次点击准备

旧实现只绘制最后两次敲击，第三次敲击会直接裁掉旧浮字。本次完整奖励仍为两组，旧组保留原始生成时间、位置与轨迹，另用 180ms 平滑退场；粒子同步淡出，后续点击不会重启旧尾迹。尾迹池有固定容量，减少动态效果同样保留退场淡出。

按压改为 80ms 缓出，松手从当时的形变继续；新的落击响应从零起步，叠加原有回弹，避免连点时跳回初始状态。初次显示提前解析和测量中英文字形。音频波形、播放器创建、预备及播放均放到专用串行后台队列，显示或重新开启声音时提前准备。静音、隐藏、休眠和退出使用所有权代次使排队请求及迟到回调失效。

当前静音可见生产视图，每秒 12 次敲击持续三秒：59.99 次绘制／秒、P95 17.81ms，无超过 25ms 的间隔，首次反馈重绘约 1.85ms；活跃进程 CPU 时间 0.382 秒，反馈结束后三秒零绘制、CPU 约 0.00028 秒。这个初次重绘测量不包含真实音频输出或实际屏幕呈现延迟。

木鱼专项验证退场边界的透明度连续性、旧轨迹时钟、形变连续性及后台音频请求取消；阻塞的空播放器工厂证明音频准备不在主线程，不播放真实音频。原生静音控制器夹具通过。逐帧检查首次按下、快速按下／释放、闲置后再点击与减少动态效果，并检查三档尺寸和两种主题。360 帧、60fps 的预览为 `.build/wooden-fish-preview/wooden-fish-fade-60fps.mp4`，360×510px。

全量 104 组回归通过（694.54 秒）。播放器重播使用暂停与归零保留准备状态，真正停止后再次预热复用已分配的播放器和 PCM；该重新预热路径也经过回归。真实音频输出、真人拖动和 VoiceOver 实操仍未新增验证，未安装或启动正式版。

开发包的身份、Widget、URL scheme、entitlements 与签名检查通过。共享目录的正式构建两次因并行任务修改网关源码而被编译器拒绝；改用 `.build/wooden-fish-source-snapshot/` 的稳定源码副本，正式包构建及同样的包检查通过。快照保留 WidgetSnapshot 符号链接，六个木鱼生产文件与当前源码逐字一致。快照内正式产物仅用于编译验证，未安装或启动。

# 迁移会话界面审查与修复

依据：用户提供的实际界面截图、SessionMigrationView 生产源码、迁移服务的能力边界。范围限于迁移工作台及其草稿状态、预览和说明文档。

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| 目标卡片随标题换行而变高 | 同一组选择项上下错位 | 统一 72pt 高度，客户端名与配置说明各一行，图标与选中标记固定占位 |
| 大窗口六个目标挤在一排 | 选项文字截断，横向阅读过长 | 工作区限制为 1120pt，目标最小宽度 190pt，最多三列 |
| 来源标题长度改变列表行布局 | 项目、状态和选择标记位置不稳定 | 标题预留两行，选中／未选中图标始终占位，完整标题与路径保留在 help |
| 窄窗口沿用宽窗口的来源区域 | 目标与提交操作被推得过远 | 保留纵向回退，紧凑列表使用 200pt 高度，横向布局使用 320pt |
| 顶部重复历史统计和大面积连接线 | 视觉顺序与下面的来源／目标选择脱节 | 简化为紧凑的来源会话到新会话摘要，消息数量集中到历史预览 |
| 携带内容的自定义开关及说明不清 | 不知道工具是否会重跑、图片会发给谁 | 改用原生复选框，常驻解释工具不会重跑、图片会发送给目标模型、文档和音频不迁移 |
| 两个 Claude、两个 Codex 的配置用途不清 | 不容易判断目标选项差异 | 补充每种目标的打开方式和配置来源，同来源 Claude 配置说明禁用原因 |
| 自定义模型没有可用供应商／模型时缺少恢复路径 | 只看到无法提交 | 显示配置供应商或添加模型的说明；官方模型字段增加常驻标签 |
| 用户／助手比例条容易被当作迁移进度 | 错误理解迁移准备状态 | 删除构成条，保留总数、大小及用户／助手条数，用明确按钮展开将携带的历史 |
| 提交禁用原因与校验分散 | 配置未填或图片不兼容时缺少明确反馈 | preparationIssue 统一校验和状态文案，空历史也禁止提交 |
| Cursor CLI 来源保留之前勾选的工具／图片 | 控件禁用但选项仍为开启，和实际能力不符 | 切换到 CLI 来源时清除不支持的选项并说明仅支持对话文本 |
| 取消旧任务后的失败可以覆盖新来源状态 | 新会话显示无关错误 | 发布迁移错误前检查版本序号，并增加取消／切换来源的生产状态回归 |
| 创建后仍在打开时提前显示成功 | 误以为操作已结束 | 打开过程优先显示进度，保留已提交记录和只打开、不重复创建的重试行为 |
| 记录摘要只写目标客户端 | 无法区分官方登录和当前配置 | 摘要显示完整目标配置名称 |
| 静态预览不能绘制原生复选框 | 占位符掩盖真实控件布局 | 使用合成数据的 NSHostingView 渲染真实控件、输入、滚动视口及明暗外观 |

验证：760／900／1440pt 合成原生窗口及空来源状态；迁移工作台状态回归、原生迁移格式／隔离回归、页面容器回归；开发版编译及包身份／签名检查。全回归结果见本次交付说明。

未执行真实客户端迁移、系统权限请求、VPN 或硬件控制；没有安装或启动正式版。键盘和 VoiceOver 的真实客户端运行路径仍需人工验证。预览采用内存服务，不读取真实历史和凭据。

# 模型网关：导入修复、真实测试与界面整理

本轮为本会话的实现与自检记录，无独立审核结论。沿用现有冰色／石墨表面、圆体与原生控件，不改供应商激活或客户端连接配置。

## 交付行为

- 导入前区分缺少 Key、HTTP、本机接口、地址格式等问题。不可导入的模型不能勾选；「修改供应商配置」关闭导入器后打开原配置，保留供应商所属客户端。批次仍需免费确认、OpenRouter 免费目录和私密保存校验。截图未提供实际 Base URL，不能据此断定 Aibox 是哪一种地址问题。
- 模型列表与拓扑详情均提供真实测试入口。测试固定选中的模型，发送最多 128 输出 tokens 的文本请求；成功须得到非空 Chat Completions 输出。测试复用并发、排队、额度、冷却和健康统计，Auto 关闭时也可测试已启用／已分配档位的模型。可以取消，退出会取消所属任务；不会切换供应商或自动重试其他模型。
- 测试不保存提示词、输出或上游错误正文；健康统计是运行时状态。基础文本测试不证明工具、图片或结构化 JSON 能力。配置变更后的旧测试不能记为当前配置的成功。
- 标题与供应商／网关工作区合并，供应商操作只出现在供应商工作区；客户端／分类／搜索和当前连接共用工具面板。网关设置说明独占完整行宽，数值／步进器／恢复按钮分别占固定位置。
- 发现目录连接选择支持搜索、选中标记、空结果与添加。短选项（路由策略、窄窗口分类）复用 `InstrumentChoiceControl`，避免 macOS 的 `Menu` 把定制标签退化成无边框文字。控件保留系统焦点、键盘和文字语义。

## 验证与边界

- 最终网关专项通过（126.94 秒）：执行生产选模／队列／网络函数，用临时配置和本会话拥有的本机 HTTP 服务验证有效输出、无效输出、401、拒绝重定向、响应头前取消、正文等待中取消、排队取消和配置变更；原三种协议、免费目录、故障切换、认证和流式取消回归继续通过。
- 以已提交基线 `1814c3e` 加本轮网关改动的隔离副本覆盖 100 个登记组：首轮 29 组通过后音频 OSLog 快照用例失败一次，该用例单独重跑通过（8.57 秒），其余 70 组通过（468.67 秒）。最后再验证 UI／原生前端／页面前端 3 组（31.86 秒）。隔离副本不包含其他会话尚在修改的 VPN／会话迁移工作。

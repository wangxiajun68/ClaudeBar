# 天气卡片雨效、文字与性能 · 2026-09-30

范围为问候卡与现有 Metal/Canvas 天气绘制。姓名内容、问候字体偏好、天气数据来源和刷新策略保持原有语义。

## 实现

- 雨纹理预烘焙出随机长短的短尾、渐细轮廓和亮头，使用真实矩形尺寸采样；远、中、近层具有不同深度、速度与透明度，每个通道独立下落，减少整片等长斜线同步平移的观感。雷雨使用更密、更快的降雨与轻微阵风，保留已有云层、闪电和玻璃水珠。Canvas 回退也缩短雨线并随机化长度、速度。
- 信息使用较高不透明度的白色文字，四角在现有 Metal 合成通道中加入固定海军蓝底色；位于雨与闪电之后，使云层、亮地平线不会淹没读数。没有新增模糊或全屏渲染通道。原生回退使用静态渐变遮罩。
- 大问候字按背景亮度选择墨色，深墨切换点从 0.42 提前至 0.18。姓名保留大小写，使用系统圆体 medium，18–28pt、0.015em 字距，使用完整覆盖而非 82% 墨量。布局处理负左侧 bearing、描边、长姓名左边界和高挑字体的实际字形高度，姓名换行后仍在仪表之间。
- 保留文本布局缓存、后台纹理栅格化、低功耗档位、屏外/遮挡暂停和 Reduce Motion 策略；没有加入粒子系统依赖、逐雨滴 SwiftUI 视图、CPU 动态粒子数组或新的 timer。

## 同机测量

命令：`python3 Tools/bench-atmosphere.py --frames 120 --contrast`。

Apple M3 Pro，1100×474pt 卡片、2200×948px drawable。11 个天气/时段，每场景预热 10 帧并计 120 帧。对比修改前同机的相同场景和量具：

| 指标 | 修改前 | 修改后 |
| --- | --- | --- |
| 大雨、雷雨前景 GPU 中位耗时 | 约 0.30 ms | 约 0.33 ms |
| 大雨、雷雨含云层刷新 GPU 中位耗时 | 约 0.40 ms | 约 0.43 ms |
| 其他场景前景 GPU 中位耗时 | 约 0.17–0.22 ms | 约 0.19–0.23 ms |
| 缓存后的文本布局 | 接近量具精度下限 | 接近量具精度下限 |
| 单次文字纹理栅格化 | 约 6.85 ms | 约 7.03 ms，live 路径已有后台队列 |

更丰富的雨形与对比度合成增加了约 0.03 ms 的雨天 GPU 成本；没有将这次视觉修改表述为 GPU 耗时下降。采样不是整机能耗或实机 FPS 对照，系统其他工作会影响时间。

量具新增 `--contrast`：在生产着色器的三帧不同相位（42、42.4、42.8 秒）取样信息标签所在的四角，按 `SkyScene.prefersDarkInk` 选中的墨色（白或 0x141E33）以 86% 覆盖合成后计算对比度。**2026-10-02 修正量具**：此前它按纯白前景取样、且沿用旧的 88pt 仪表高度，两项都让读数不再代表卡片（见下）。修正后 11 个场景的最弱区域中位数为 **3.41:1**（阴天左上时钟），其余晴天 3.57–5.84:1、雨/雷/夜晚 6.9–13.5:1；门槛取 3:1（该处墨色为 22–28pt 大字号，WCAG 大字号下限），量具同时打印每个场景的最差单像素，方便看极端值（月亮、闪电、日晕会落进取样框）。这验证信息区的墨色在天空上稳定可读；不代表每个字形边缘、过渡入场、整个画面或所有天文位置都已逐像素验收。

## 验证

- `make test`：34 组通过。新增 `greeting-layout` 登记在 Makefile，编译生产布局/字形函数，覆盖 24 种字体 × 4 宽度 × 4 问候语 × 5 姓名，即 1,920 个组合；验证字形与姓名边界、仪表避让、名字大小写、缓存一致性、纹理生成和日夜墨色。
- `make build` / `make release`：仅构建 dev/release，身份、Widget、URL scheme、entitlements 与签名检查；不安装或启动正式版。
- `python3 Tools/render-greeting-preview.py --weather-review`：合成数据、临时 argument domain、主卡与手动控制台，1100pt 与 620pt。预览器补齐当前组件文件和 BuildChannel 依赖，并修复窄宽度 fixture 未传入卡片的问题。检查晴、小雨、大雨、雷雨、阴、雪、雾、夜间、缺读数及手动控制台样本。
- 未启动真实 VPN、SMC 或正式版应用。尚未进行真实窗口的滚动帧率、动画 hitch 和整机功耗测量。

预览与量具日志在 `.build/greeting-preview` 和 `.build/weather-benchmark-contrast.log`；均为可再生成的本地验证产物，不进入发布资源。

## 太阳事件求解微基准

复用生产 `SkyAstronomy.swift`、`swiftc -O`、广州坐标 23.13 / 113.26、Asia/Shanghai，连续 32 个日期冷求解，再循环这 32 个日期执行 10,000 次缓存读取；累加时间戳避免无效代码消除。当前机器冷求解平均约 128.68 µs/日，缓存读取约 1.18 µs/次。该数据仅衡量日期事件解析，不代表窗口帧率或整机功耗；缓存容量为 32，地点/日期变化会失效。

# 多屏灵动岛验证记录

范围：内置屏＋外接显示器的入口、提醒归属、显示偏好与面板生命周期。复用现有数据模型与内容，未安装或启动正式版，未修改 VPN、系统代理、硬件控制或外部客户端。

## 视觉

生产视图预览覆盖硬件刘海与外接胶囊、收起／提醒／展开、两种主题背景。外接胶囊为 154×28pt，状态与用量直接排列，关闭读数后仍保留最小入口；圆角、字体、轮廓、菜单栏下方留白与透明点击区域一致。展开沿用现有会话宫格与用量卡。

单独提取生产 `islandSettings`、SettingsControls 和 InstrumentToggleStyle，检查所有屏幕与指定显示器未连接两种状态、两种主题、640pt 内容宽度。文案、原生菜单与开关均未裁切；设置页重新进入时刷新当前显示器清单。

预览位于 `.build/island-preview/`，`external-display-preview.jpg` 为外接形态组合图；`settings-all-light.png`、`settings-selected-dark.png` 为设置检查示例。该图片使用合成会话与用量，不是用户数据。

## 交互与所有权

`island-display` 回归直接编译生产控制器、几何和视图，仅替换系统输入、数据存储、通知和触觉边界。原生面板放在合成的离屏坐标，退出前关闭。覆盖：

- 双入口、单模型、单处展开、普通悬停与跨屏停留。
- 透明圆角穿透、形状命中缓存、普通鼠标移动不启动计时器。
- 按住或拖动时不切换／收起详情；上下屏边界不会误触下方刘海。
- 提醒选鼠标所在屏，出现后保持原屏；拔掉屏幕保留事件与剩余期限。
- 指定屏断开时回退、重连恢复，镜像去重与负坐标。
- 已关闭面板的旧点击回调失效；同一 UUID 重连也不向旧面板授予操作权。
- 无可用屏幕与详情已展开时继续执行原有待确认通知兜底。
- 显示偏好、全屏集合行为、最小入口与共享周期刷新、退出取消悬停和检查计时器。

`island-coalescing`、`island-session-alert` 和 `waiting-notify` 一并验证。原先等待通知夹具缺少新的“可用入口”输入，已同步，并增加无屏幕情况下的通知兜底用例。

## 性能与真实屏幕几何

一次合成夹具测量：100,000 次缓存胶囊命中约 196.77ms，100,000 次静置双屏指针处理约 726.86ms。该数据为本机合成输入的耗时，不能等同于应用 CPU 或屏幕帧率。静置没有离开计时器，只有一对鼠标监听；打开时共用一个 10Hz 检查计时器，路径与捕获标志均复用。

只读读取到本机两块屏幕：Mi Monitor 为 `(0, 0, 2560, 1440)`，胶囊顶边内缩 38pt（菜单栏 30pt＋留白 8pt）；Built-in Retina Display 为 `(275, -1117, 1728, 1117)`，真实刘海为 185×32pt。两者上下相邻，符合新增的顶边跨屏回归场景。读取没有录屏、移动鼠标、请求权限或改变显示器设置。

## 验证边界

真实显示器拔插、合盖、全屏 Space、混合 DPI 切换和 VoiceOver 实操仍需人工验证。原生面板夹具和集合行为检查不能代替这些系统场景，也不构成 120Hz 实际呈现保证。

全量 105 组回归通过（805.32 秒）；最后的面板身份校验另外通过四组岛相关专项（35.22 秒）。开发包与稳定源码快照的正式包均通过构建、版本身份、Widget、URL scheme、entitlements 与签名校验。六个涉及多屏的生产文件与正式源码快照逐字一致。正式产物位于 `.build/island-display-build-snapshot/.build/release/ClaudeBar.app`，仅用于校验，未安装或启动。

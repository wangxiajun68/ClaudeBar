## 构图与节奏

天气只保留四秒开场。Popup 与岛各六秒，桌面五秒；会话、用量和请求八秒连续交接；网关八秒；VPN、文档与 CLI 九秒；收尾六秒。动作保持入场、停稳与退出，主体正面停留阶段可辨认关键模块。

环境为深蓝石墨 #080D15 与 #223A4B，主字 #F2F7FA，说明 #B9CBD7。透视 1600px，中心 50% / 46%；前后景有不同深度、旋转与速度。文字位于底部独立留白带或 Popup 左侧，不压在产品表面。

真实生产视图不经 AI 重绘；固定演示数据与镜头编排明确区分。CLI 沿用仓库合成演示图。README 单独提供原始 Popup 与双显示器岛示例。

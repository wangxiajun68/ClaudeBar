# ClaudeBar 宣传影片的空间设计

范围为宣传影片与本地播放器，原生应用根 DESIGN.md 不变。模式为 Persuade / Experience：通过界面自身的设计与连续运动，理解天气卡片、popup、灵动岛和桌面工作台之间的关系。

## 空间与层次

1920×1080，CSS perspective=1600px，透视中心在画布50%/46%。界面使用 translate3d / rotateX / rotateY / rotateZ，最大正深度仅用于片头从特写拉出的镜头。背景环境光、透视地面、产品面板、前景雨线和固定文案形成不同运动层。

深蓝石墨底色 `#080D15`，上方 `#223A4B` 环境反光，主字 `#F2F7FA`，说明 `#B9CBD7`，层说明 `#93BDCF`。真实产品纹理保持原生色彩。产品阴影 `0 45px 90px #0008`；天气卡阴影更宽，岛保持近黑轮廓。圆角遵循各表面的纹理轮廓。

文字位于底部901px的独立带，或popup左侧125px/390px处。普通标题58px，popup两行标题76px，说明25–27px；系统字体与原生界面一致。片头天空从特写拉至完整卡片，popup分层停留时每层不透明、留有间隔，避免重叠正文。

## 编排

66秒，30fps，6章。天气0–10s、popup10–22s、灵动岛22–33s、桌面33–46s、工作视图46–58s、收尾58–66s。元素跨章继续运动；不用重复的淡入静置淡出。

天气晴云雨夜交叠，阵雨有36条前景雨线。Popup先完整展示，随后模型、会话、用量三块按不同深度与角度展开，再合拢。岛按常驻、提醒、展开的真实源图连续变形，并向屏幕顶边归位。桌面主窗口拥有标题栏和固定比例视口，长内容通过滚动展示。会话、用量、流量从同一空间轨道旋入并停稳。最后几种表面汇集，再收束到品牌图标。

## 实现与边界

帧是给定t的确定性函数，不使用动画实时钟。源纹理来自当前Swift视图与固定演示数据；空间分层、模拟桌面和镜头是宣传编排，不是应用本身具有的操作，也不称作录屏。

播放器沿用原有响应式结构、原生播放控件与视频外字幕。章节按钮与成片秒数同步。本地服务有字节范围支持以保证seek。片头、展开层、完整岛和主窗口停留状态均需查看高清截图；动效需查看时间跨度而非只看中间静帧。

# ClaudeBar 宣传影片 · 场景提示词（Scene Prompt）

> 本文是 `docs/promo/claudebar.mp4` 的**唯一规格**。影片不是屏幕录制，而是一台
> 渲染出来的时序动画：每个场景渲染成一串确定性的帧，再用 ffmpeg 编成 H.264。
> 因此下文每一句都是可执行的约束——**尺寸、字体、色值、时刻、缓动都必须是数字**，
> 不能出现"大气一点的蓝""稍微快一点"这类无法落地的描述。
>
> 产物：`docs/promo/claudebar.mp4`（1920×1080 / 30 fps / H.264 / yuv420p / +faststart），
> 首帧化出的 `docs/promo/claudebar.gif`（1280 宽，约 20 MB 以内），以及 README 里的嵌入。
> 生成器：`Tools/render-promo-film.py`；帧与视频不进 git（`.gitignore`）。

## 0. 总体设计原则

参考对象是 Apple 产品影片，但它给的是**手法**，不是皮肤。ClaudeBar 不是 iPhone，
所以影片继承的是三件事：**留白、单一主角、镜头运动**，而不是黑底产品浮在光里。

| 原则 | 落到本片的具体做法 | 明确不做 |
| --- | --- | --- |
| **每场一个主角** | 每一场只允许一个元素获得最大对比度与最大面积；其余元素降到次层或辅层（对齐 `docs/design/greeting-atmosphere.md` §2.4 的三层权重，主:次:辅 ≈ 6:1:0.5） | 一屏同时出现 popup + 主窗口 + 天气卡 |
| **放大缩小就是叙事** | 全片只有三种镜头动作：**推近**（揭示细节）、**拉远**（从局部看见全局）、**静置**（让观众读）。每种都有明确的起止尺度 | 无源的随机抖动、"呼吸感"缩放 |
| **层次感来自焦平面** | 每次推近/拉远时，前景（产品面板）与背景（画布辉光、网格）**不同速**移动：背景位移 = 前景位移 × 0.35 | 所有元素同速平移（读起来像 2D 贴纸滑动） |
| **颜色只出现在数据里** | 画面基底是冰面 `#EEF3F8` / 石墨 `#16181C`；彩色只出现在图表、状态、品牌 mark 与灵动岛的数据色 | 大面积的蓝紫渐变背景、彩虹字、发光描边标题 |
| **光影克制** | 只有两处允许辉光：① 灵动岛的轮廓光，② 天气卡自身的天空。其余用 1px 发丝线与 4% 黑阴影分层（对齐 `Theme.PanelCardModifier`） | 卡片大面积 backdrop-blur、彩色 glow 阴影 |
| **字是产品的一部分** | 文案只用应用真实措辞（`docs/design/04-popup-layout.md`、`greeting-atmosphere.md`）；问候语用手写体（Borel，随包） | 自造 slogan、全大写的营销短语、emoji |
| **不留水印** | 宣传帧里不出现"示例数据""Preview"字样 | 把开发用的调试文案带进成片 |

**观众是谁**：正在同时跑 Claude Code / Codex / Cursor 的开发者。他们不需要被说服
"AI 很重要"，只需要在两分钟内看清"这个东西把哪四件事收进了顶栏"。所以每场都
以**一个动作**结尾（点一下、悬停、展开、切过去），而不是以"更强大"结尾。

## 1. 技术规格

| 项 | 值 |
| --- | --- |
| 画布 | 1920 × 1080，sRGB，`-webkit-font-smoothing: antialiased` |
| 帧率 | 30 fps；每场帧数 = 时长 × 30，逐帧渲染（`?t=<秒>` 驱动全部状态） |
| 确定性 | 同一 `t` 必须渲染出**逐像素相同**的帧：天空、粒子、数字变化全部是 `t` 的纯函数；随机源用固定种子（闪电、雪花、星点抖动） |
| 字体 | 系统 SF Pro / SF Rounded / SF Mono；问候语手写体用随包 `Sources/Fonts/Borel-Regular.ttf`（若渲染器取不到字体则回落 Snell Roundhand，并在日志里说明） |
| 取景 | 所有面板截图按其**真实 pt 尺寸**绘制，再乘以统一缩放系数；1080 高的画面上，主窗口取 0.72–0.86 倍，popup 取 1.0–1.35 倍 |
| 编码 | `ffmpeg -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p -movflags +faststart -r 30` |
| 时长 | 118 秒（30 fps → 3540 帧） |
| 声音 | 无（静音成片）。README 里自动播放的 GIF 本身也没有音轨 |

**全片节奏**（同一套缓动名，供逐场引用）：

| 名 | 曲线 | 用途 |
| --- | --- | --- |
| `film.slow` | `cubic-bezier(0.4, 0, 0.2, 1)`，1.1–1.6 s | 镜头推近 / 拉远、明暗切换 |
| `film.enter` | `cubic-bezier(0.16, 1, 0.3, 1)`，0.9 s | 元素入场（自带"停稳"感） |
| `film.snap` | `cubic-bezier(0.34, 1.56, 0.64, 1)`，0.38 s | 点击回弹、岛上内容浮出 |
| `film.hold` | 无 | 让观众读完；每场至少留 1.6 s 静止 |
| `film.wipe` | `cubic-bezier(0.65, 0, 0.35, 1)`，0.5 s | 场与场之间的黑场 / 白场过渡 |

## 2. 镜头语法

```
推近 push-in     scale 1.00 → 1.14，同时背景 scale 1.00 → 1.05，前景位移 −26pt，背景位移 −9pt
拉远 pull-out    scale 1.14 → 1.00（同上反向），结尾加 80ms 的 0.5% 过冲
静置 hold        只允许两样东西动：数据在变（token 数字、心跳 sparkline、雨丝），镜头不动
转场 wipe        500ms 单色覆盖（白场用于浅场之间，黑场用于入/出深场）
```

**景深规则**：镜头推近时，主角保持全对比度，背景层同时 `blur 0 → 2pt、opacity 1 → 0.72`；
拉远时反向。这样"放大"读起来是**凑近看**，而不是**放大一张图**。

**永不使用**：旋转、翻转、透视扭曲、粒子爆炸、逐字打字机（问候语除外，它的入场本身就是
书写过程，见 §4 第 3 场）。

| 元素 | 规格 |

## 4. 场景表

时间轴以秒记，`入 → 出` 是可见窗口。每场都写明：**镜头 / 主角 / 元素 / 动作 / 文案 / 层次**。

### 第 1 场 · 开场（0:00.00 – 0:06.60）

- **镜头**：静置，仅 mark 有 1.15 倍的微推近（`scale 1.00 → 1.02`，`film.slow`）。
- **主角**：ClaudeBar 品牌 mark。
- **元素**：冰面画布；居中 mark 188pt；其下 32pt 处 `ClaudeBar`（84pt，600）；再下 22pt 一句
  `菜单栏里的 AI 工作台`（28pt，`#86868b`）；再下 28pt 一枚 17pt 灰字 `macOS 15 · Apple Silicon · MIT`（字距 0.04em）。
- **动作**：0.15 s mark 从 `opacity 0 / y +18` 进入；1.15 s 名字与副句各自延后 120 ms 依次到位；
  4.6 s 起整组 `opacity → 0 / y −14`（0.8 s）。
- **文案**：`ClaudeBar`、`菜单栏里的 AI 工作台`、`macOS 15 · Apple Silicon · MIT`
- **层次**：mark 是唯一有阴影的东西；文字没有阴影、没有渐变。

### 第 2 场 · 引出问题（0:06.30 – 0:15.20）

- **镜头**：不推近，改为**横向漂移**：四个小图标从左到右以 0.9 倍速通过画面（背景层 0.35 倍速）。
- **主角**：四个被"挤在一起"的小图标（VPN 药丸、代理方框、模型切换器、会话列表）。
- **元素**：它们各自占一个 120pt 的圆角方块（`#FFFFFF` @ 0.9，圆角 26pt），互相**重叠 18pt**，
  说明"每人一个托盘图标"；下方一条发丝线；线下一行正文。
- **动作**：重叠的四方块在 11.2 s 缩到 0.92 并挤得更紧（象征拥挤），随后整组向左滑出。
- **文案**：主标题 `四个图标。`（84pt）；正文 `以前每切一次模型，就要离开终端一次。`（24pt）
- **层次**：方块是骨架，图标是单色 `#6e6e73`（**不给品牌色**——这一场讲的是杂乱，不是身份）。

### 第 3 场 · 问候卡 · 天空（0:15.00 – 0:31.20）

- **镜头**：**推近**。0:15.0 时卡片以 `scale 0.86 / opacity 0` 在左下出现，1.4 s 内到 `scale 1.00`；
  0:19.4 起推近到 `scale 1.10`，镜头中心从卡片中心移到问候语基线（`y = H × 0.62`），
  推近结束时问候语正好占满画面宽度的 62%。
- **主角**：问候卡（`docs/design/greeting-atmosphere.md` 的 `GreetingStatusSheet`）。
- **元素**：天空（Metal 大气：渐变 + 体积云 + 天体）、问候语 `good morning,`、签名 `XIAJUN WANG`、
  左上是时钟与自动/手动、右上是城市与天气读数、左下日轨、右侧六日预报、底部窗台（模型胶囊、Cursor 两池、Codex 两窗口、今日 token）。
- **动作**：
  - 0:19.4–0:23.0 天空**从清晨走到正午**：太阳高度角连续插值，云量从 0.78 走到 0.52，色温 5800K；
  - 0:23.0–0:27.4 切到**日落**：地平线 `#FF9656`，问候语一侧出现 0.34 强度的金色边缘光；
  - 0:27.4–0:31.2 切到**夜**：星空渐显（−6° 到 −18° 之间由 0 线性到 100%），月亮带月相终结线，
    问候语换成 `good evening,`；
  - 全过程中数字不许跳：温度、token 都按线性插值走。
- **文案**（都是应用真实措辞）：`good morning,` / `good evening,` / `XIAJUN WANG` / `广州 · 29° 多云` /
  `体感 32° · 湿 78% · 东南 3级` / `日落 18:21 · 拖动天空，漫游一天`
- **层次**：天空是底（唯一允许饱和度高的层），问候语是主（玻璃字，折射天空），
  铭文与窗台是辅（≤ 60% 不透明度、11pt）。**卡片内部只允许一层玻璃**（窗台），不再套第二层卡片。
- **逐字入场**（只在 0:15.0 那一次出现，全片仅此一次）：每个字形 `blur 12 → 0 / y +18 → 0 / opacity 0 → 1`，
  字间 35 ms，每字 700 ms，`ink.spring`；随后一道边缘光从左到右扫过 600 ms。

### 第 4 场 · 天气卡 · 玻璃雨（0:31.00 – 0:42.20）

- **镜头**：**静止的特写**。卡片保持 `scale 1.22`，取景只取卡片左上三分之二（天气区 + 问候语上半），
  让雨丝从字前划过这件事被看见。
- **主角**：卡片表面的雨滴（`WeatherBackdrop` 的 L7 层）。
- **元素**：小雨（远层 220 条 14pt 雨丝、近层 30 条 38pt 虚焦雨滴）、卡面 2–7pt 折射雨滴、
  问候语（此刻是主焦平面，雨滴在它前面）。
- **动作**：0:34.0 起一颗半径 5.5pt 的雨滴落下（120 ms 从 0 放大到 1，配 260 ms 扩散到 3 倍半径的涟漪），
  0:36.2 开始下滑（速度 22pt/s，路径带 sin 抖动，身后留 1.2 s 衰减的湿痕）；
  0:38.6 指针（一个 6pt 的柔和圆点）横向划过，拨开雨滴；0:40.4 点击空白处，附近雨滴合并成一颗并立刻下滑。
- **文案**：主标题 `雨在字前面。`（84pt）；正文 `文字本身是场景的一部分：云影从字面掠过，雨丝从字前划过。`（24pt）
- **层次**：手势的三步（落、滑、拨）各给 1.2 s 的静止，让观众看清这是**可交互**的，不是贴图动画。

### 第 5 场 · 灵动岛 · 收起（0:42.00 – 0:51.00）

- **镜头**：**拉远**。0:42.0 从第 4 场的卡片特写快速拉远（1.0 s），画面露出屏幕顶边；
  卡片滑到下缘之外，顶边成为构图的上三分之一。
- **主角**：刘海两侧的两翼。
- **元素**：屏幕顶边（一条 46pt 高的黑色 notch 形，含两侧 `topFlare 6pt`）；左翼 52pt：
  运行中 Agent 的品牌 mark 18pt + 旋转轨道 + 数量 `2`；右翼 52pt：今日 token `3.1亿`；
  菜单栏右侧是状态项本身——`Sources/MenuBarIcon.png` + 双行 ↓/↑ 速率（白色）+ 电池格与电量；
  另有 popup 里的 VPN 药丸一颗（`VpnStatusPill`），它是速率变绿的那一颗。
- **动作**：0:45.4 左翼的轨道加速一圈（`rotationEffect` 一次 0.9 s 的完整旋转），
  右翼数字从 `3.09亿` 逐位滚到 `3.12亿`（`.numericText`，240 ms）。
- **文案**：无（这是"余光界面"，加字就否定了它的设计）
- **层次**：岛在两种背景下都必须是纯黑 `#000`、**不描边、不投影**；只有状态项的图标是有颜色的东西。

### 第 6 场 · 灵动岛 · 完成提醒（0:50.80 – 1:01.40）

- **镜头**：静置，但在 0:53.2 提醒出现的同一帧做一次 **1.03 的微推**（`film.snap`，回到 1.00）。
- **主角**：提醒条。
- **元素**：`max(380, notch + 212)` 宽 × `notch + 54` 高的黑岛；左侧 Agent mark 20pt；
  文字 `ClaudeBar`；下一行 `Claude Code · opus · 等待你的下一步`；右侧 `继续 ↗` 按钮（12pt，薄荷色文字）。
  底部圆角 22pt，1px `#FFFFFF` @ 9% 轮廓光。
- **动作**：
  - 0:53.2 岛从收起的 46pt 高**长到** 100pt（`alertSpring: response 0.46 / damping 0.72`，略带回弹）；
  - 同一帧一道身份色（Claude 陶土 `#E8845E`）光沿岛的下沿从左扫到右，600 ms，只扫一次；
  - 0:55.0 与 0:57.0 各有一只 `继续 ↗` 悬停高亮（`#FFFFFF` @ 6% 底）；
  - 6 s 倒计时以一条 1pt 的进度线画在岛的下缘内侧（薄荷 → 透明）；
  - 1:00.6 点击 `继续`，岛收回 46pt（`collapseSpring: 0.34 / 0.92`）。
- **文案**：`ClaudeBar`、`Claude Code · opus · 等待你的下一步`、`继续 ↗`
- **层次**：提醒是全片唯一允许"光扫过"的地方；同一时刻画面上不许有第二个高亮元素。

### 第 7 场 · 灵动岛 · 展开（1:01.20 – 1:13.60）

- **镜头**：**推近**。0:58.0 起镜头以 1.3 倍速下移并推近，1:04.0 停在 `scale 1.25`，
  取景只有岛；岛下缘到画面下缘留 120pt 空气。
- **主角**：展开态的岛。
- **元素**：
  - 顶栏（与刘海等高）：左侧当前路由 `( ◇ ) DeepSeek · v4`，右侧 `● 代理` 与 `⧉` 按钮；
  - 会话格 2 列 × 2 行，每行 44pt：mark、目录名、上下文"油量"条、本次花费；
    四条为 `ClaudeBar ▰▰▱ 62%`、`api… ▰▱▱ 12%`、`api-server ▰▱▱ 8%`、`cursor ▰▰▱ 40%`；
  - 底行 `4 个会话 · 上下滑动查看更多`；
  - 用量卡 156pt：`今日 3.1亿`、`今日花费 ¥128.40`、30 天直方图（Canvas 绘制 30 根柱）、
    `昨日的 112% · 1,204 次`、`本月 33.9亿 上月同期 99%`、来源分段条（CC 陶土 / Codex 钴蓝 / 第三方 品红）。
- **动作**：
  - 1:02.0 展开：宽 `max(520, notch + 320)`、高 `notch + 6 + 会话带 + 8 + 156 + 12`，
    `expandSpring: 0.42 / 0.80`；内容 `opacity 0→1` 且从 94% 向顶边放大；
  - 1:05.6 指针纵向滚过会话格，第三条被滚上来（滚动时长 0.9 s，带惯性尾巴）；
  - 1:08.2 指针停在第 30 天的那根柱上，直方图**滑动**到该日：柱列整体平移，被指的那根升到 100% 高亮，
    上方浮出一行 `9月12日 · 1.42亿 · ¥57.60`（`film.snap`，0.28 s）；
  - 1:11.0 来源分段条逐段点亮（每段 120 ms，段内数字 `43.4% / 51.2% / 5.4%`）。
- **文案**：`DeepSeek · v4`、`代理`、`今日 3.1亿`、`今日花费 ¥128.40`、`昨日的 112% · 1,204 次`、
  `本月 33.9亿 上月同期 99%`、`CC / Codex / 第三方`、`4 个会话 · 上下滑动查看更多`
- **层次**：会话格是"名单"（等宽排列、无卡片），用量卡是"读数"（只此一张卡）；两者之间用 8pt 间距 + 发丝线，不叠卡。

### 第 8 场 · Popup · 一眼三格（1:13.40 – 1:26.80）

- **镜头**：切换主角。1:13.4 岛收回到顶边（0.5 s），popup 从左下 `scale 0.9 / opacity 0` 进入
  （0.9 s，`film.enter`），随后 **推近到 1.12**，取景只有 popup 的上半（状态行 + 切换行 + KPI 条）。

   同一套路——把生产 Swift 文件里的类型声明抽出来拼接成一份 `Probe.swift`，用 `swiftc` 编成
   无界面可执行文件，`ImageRenderer` 出 PNG。popup / 灵动岛 / 主窗口各出一份"合成数据快照"，

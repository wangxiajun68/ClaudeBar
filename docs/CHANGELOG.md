## [1.16.0] — 2026-10-08

新增 Matrix CLI 终端观测台（`mtx`）与性能模式；会话迁移支持携带图片与原生工具记录；VPN 系统代理写入串行化并修掉故障切换、漏网分析与退出清理的多个竞态；按页复核并优化了表格、热图、用量索引、连接器、天气卡片与原生编辑器的重复工作。

### 新增

- **Matrix CLI 系统观测台**：新增原生 `mtx` / `mtx-dev` 短命令（Matrix，兼容 `claudebar` / `claudebar-dev`），随应用一起构建并嵌套签名。提供多色终端总览、大字问候、日期日历、缓存天气与城市刷新、资源专用命令、Agent 统计、模型排名、健康提示、完整会话数量与状态、本机资源、用量、额度、供应商、VPN、代理、连接器，以及 JSON / NDJSON 与 `watch` 实时刷新；常用命令、子命令与参数支持固定缩写，`mtx -w 1` 常驻每秒刷新。私有快照带时间与过期标记，开发版保持独立身份与系统集成限制。见 [CLI 使用说明](CLI.md)。
- **MTX 交互终端与命令栏**：`mtx -w 1` 支持键盘与鼠标滚动、七个页面、搜索、记录详情、冻结视图和 CPU 微型曲线；刷新保留位置并仅重绘变化行。命令栏通过本地控制接口执行模型、VPN、连接器与模式操作，目录可搜索并查看完整 ID。
- **MTX 控制接口与性能模式**：CLI 支持 Claude / Codex 的供应商和模型切换、VPN 启停、节点预览与选择、连接器启停与删除、应用启动退出及偏好设置。控制走同用户本地 socket（64 KiB 请求 / 4 MiB 响应上限，校验目录与端点属主），应用侧在主 actor 路由到既有生产 store，变更类操作串行化。性能模式释放前端、关闭 popup 与灵动岛、隐藏 Dock 图标，后台功能与 CLI 保留，可经 `mtx mode desktop` 恢复；帮助页新增「CLI 与性能模式」。
- **会话迁移**：会话卡片可把已结束的 Claude Code、Codex 或 Cursor 正文创建为 Claude Code、Codex 当前配置/官方登录、Cursor CLI 或 Cursor 桌面的新原生会话；迁移记录关联来源及再次迁移。Claude Code / Codex / Cursor 桌面可选择携带已完成工具。Claude Code 与 Codex 写成相邻的原生工具调用和结果，并生成新的调用 ID；Cursor 桌面只写回样本里已有的工具编号。也可选择把 png、jpeg、webp、gif 或图片地址写入目标图片字段；Cursor 桌面写入该项目的图片目录。两个选项同时打开时，工具结果里的图片不放进工具输出文本。Cursor CLI 仍不写入图片，`attachedFiles`、文档和音频仍拒绝。官方套餐请求去掉订阅不接受的采样参数，且不读取 Codex 登录文件。Cursor 桌面跟随项目已有模型，并直接定位打开迁移聊天。新增「Claude Code · Codex 自定义模型」，以独立会话路由沿用已保存的 Responses / Chat 供应商和模型，不改全局选择；Kimi、DeepSeek 的真实 Read/Write、错误结果和冷恢复已验证。固定已验证客户端版本，未知版本、压缩、子代理、文档音频及不完整历史明确拒绝。开发版保持系统集成禁用，官方套餐跨客户端授权尚未接入。见 [会话迁移契约](technical/session-migration.md) 与 [第三阶段完整报告](reviews/session-migration-phase3-implementation-2026-10-03.md)。
- **飞书文档组件**：正文嵌入官方云文档组件并按其要求做原生签名；鉴权前显式要求 `drive:drive` 并给出可读失败原因，组件失败只透传数字平台码（不透传可能含签名 URL 的原始错误），失败时降级到正文阅读并可重试。

### 变更

- **正式版默认不带 Dock 图标**：应用改以 `LSUIElement=true` 起步，桌面模式才显式切换为常规激活策略；`--performance` / `--desktop` 与 `mtx mode` 可切换。
- **VPN 系统代理写入串行化**：写入改为单通道并回读覆盖全部服务，守卫失败退避；故障切换日志游标整行进位，就绪判定要求版本号，日志轮转后重取尾偏移；关闭 VPN 后不再被 `reloadConfig` 的延迟重启拉起来；退出时不再把系统代理留在死端口上。
- **供应商与迁移的取数收紧**：获取模型列表不再允许对公网使用明文 http；迁移的 Codex 目标目录改用本地自然日。

### 性能

- **文档表格与原生编辑器**：表格按行分组导出、预计算行列坐标并缓存布局（焦点/选择/编辑模式变化不再重跑布局），静态单元格文本与目录标题抽成只依赖自身输入的叶子视图；原生编辑器首次写入后不再重复解析与赋值。
- **用量热图、流量与 KDE**：热图把 Calendar 运算与日期键格式化移出 Canvas 绘制闭包，悬停状态移入局部视图；流量过滤缓存按已匹配 ID 更新值副本，不再重跑整轮搜索；相同 Token 总量的 Gaussian 核只算一次并按出现次数加权。
- **用量索引与会话家族归属**：JSON 后端维护路径与日期两套汇总键索引，窄区间二分查找、宽区间选扫描；会话家族查询改为每个文件一次路由到所属家族，Codex 用迭代父链与共享祖先链接，环内节点共享结果。
- **连接器、供应商与概览**：连接器库存同一时刻只跑一轮扫描、过滤与归属统计按输入缓存；模型目录端点改静态索引，提供商分区缓存；概览只格式化可见的会话行。
- **天气卡片与动效**：Reduce Motion 静态天空按输入/尺寸/scale 缓存并在串行队列等待 GPU 回读，就绪前保留上一张图；文字栅格化只在键仍等于最新请求时安装；Metal 视图在 `draw` 与 `kick` 重查遮挡、滚动定帧与 Reduce Motion；能源流按路径、外观与播放速度增量更新图层。
- **后台与访问日志**：请求日志构造不读盘、首次显示后台倒读文件尾部并按 100 ms 合批发布；能源流、额度、VPN 与资源采样定时器增加容差；第三方用量按日期区间查询，Cursor 转录尾扫描改反向读并在边界提前停止。

### 修复

- **首页天气渲染开关**：关闭后，手动天空模式与缓存天气不再显示云雨雪、实时天气图标或温度；天空模式按钮正确显示关闭状态，重新开启保留之前的手动选择。
- **超出范围与并发批次**：多处越界整数、风级、湿度、超大 token 值与 `Double`→`Int64` 转换不再 trap；并行工具批次不再被判成没有待办；长 prompt 不再丢标题。
- **额度与用量账本**：失败的额度查询不再抹掉读数与重置状态，窗口按载荷槽位记账；claims 台账的压实条件写反导致每次 flush 整体重写已修；Claude `message.id` 在整个语料内只记一次。
- **访问日志与抓包**：磁盘记录的两个崩溃 / 丢行路径已修，压缩只写已封口记录；载荷写入失败不再留下只有壳的记录；详情面板不再跨记录串台或永久转圈。
- **会话与监控**：Codex 打开的回合不再被大段工具输出判成空闲；Cursor 子 agent 可展开查看；Codex 会话模型优先取索引行；Codex 判定只扫 argv，不再把环境变量当命令行。
- **天气与问候**：中国天气网当天格按单元格自身日期选，凌晨不再显示昨天的预报；极昼肩部日不再返回颠倒的日出/日落对；两位风级按一个数读；越界数值不再炸进程。
- **VPN 与连接器**：漏网分析只在无筛选的汇总上做，路由/失败筛选不再制造假泄漏；删除订阅后仅当移除的是当前订阅才重启内核；连接器的 Skill 启停改为仅移库并修复移库后符号链接无法还原。
- **飞书、迁移与权限**：副本不再被当成 file、超时导入不再报成功；迁移工具结果内容无条件检查，文档/音频不再随「整体省略」消失；开发版不再全局抢占 ⌘⇧A；「读取 Cursor 会话」真的关掉 Cursor 读路径。
- **窗口与界面**：导航请求在 `willSet` 投递里清除会被丢弃、重开窗口后重放陈旧页面；命令面板 Return 单路触发，方向键选中项滚动进视野；详情页不再卡在转圈、全选不再吞掉已勾选。
- **构建与缓存**：未标注版本的编译落在 dev 身份；构建缓存不再留孤儿对象。

### 内部

- **发布回归稳定性**：CLI 控制测试通过开始/释放信号验证变更串行化与断连取消，风扇命令夹具等待实际结果而非固定延时；迁移测试的延迟 SQLite 写入使用有界忙等待，避免与读取事务竞争时立即失败；优化编译下的失败断言输出位置与原因，便于定位 CI 故障。
- **音频日志回归窗口**：用唯一日志标记确认持久化，查询起点固定在缓存快照边界之后；覆盖超过一秒的查询延迟，避免 CI 上的动态时间窗口漏掉测试记录。
- 新增 `cli` / `cli-control` / `module-performance` / `backend-performance` / `access-log-tail` / `ui-animation-performance` / `page-frontend` / `core-algorithms` 等源码切片回归，全部登记进 `Makefile`。
- 新增多份审查文档与脱敏测量（`docs/reviews/`），覆盖模块、后端、UI 动效、正式版 Instruments 采样与逐页前端；`Tools/performance-inventory.py` 可按日期产出带源码哈希的入口清单。
- `Tools/build-cache.py` 的指纹纳入共享 Swift 身份文件，构建脚本改动会使缓存失效。

## [1.15.0] — 2026-10-03

新增飞书文档工作区；Claude Code workflow 状态进入会话页；问候语支持诗词、日常问候与节气；模型可配置 Claude Code 并发上限。

### 新增

- **飞书文档工作区**：连接器页新增「飞书文档」，提供云空间、个人文档库、知识空间与 Wiki 的浏览、搜索与分页，Docx / Wiki 的 Markdown 排版与直接编辑，以及创建、重命名、移动、删除、上传导入、导出，和评论、协作者、历史版本管理。使用已安装的官方 `lark-cli`，应用不安装、不升级、不保存令牌。开发版只显示示例数据，真实 CLI 调用按版本身份在进程入口拒绝，写操作再次拒绝。见 [飞书文档工作区](FEISHU_DOCUMENTS.md)。
- **会话页显示 Claude Code workflow 状态**：显示 workflow 名称、状态、当前或最近阶段、已返回结果的 agent 数与已发现总数。数据只读 Claude Code 自身的 `journal.jsonl` 与主会话 JSONL，不装 hook、不改配置、不起会话。所有 agent 返回不等于 workflow 完成，终态必须来自明确事件；进程退出或 90 秒无活动证据时显示「状态未知」。见 [workflow 状态监控](WORKFLOW_MONITORING.md)。
- **问候语可摘古诗词，并随节气变化**：新增「诗词」选项，按当季节气或季节摘句；中文取古诗词，英文取公共领域英诗。节气使用离线日历（2026–2030，香港天文台年历）。「自动」模式在节日与恶劣天气之后同样落到诗句，深夜优先提醒休息。
- **问候语新增「日常问候」**：只保留基本的日常话语，按时辰轮换，不引用诗词，不掺天气。
- **问候语可以自己挑**：从「自动」切到固定的一句、「你好，本月」，或自定义一句（最多 80 字，留空回到自动）；固定与自定义内容不随时间、节日和天气变化。
- **创意字体选择与管理**：提供 14 款中文、39 款英文字体；字形预览默认折叠，支持搜索、删除与恢复，每种语言至少保留一款。删除清除本地字体文件与字形缓存，恢复从随包原件复制。
- **天气渲染可以关掉**：设置 → 天气与问候新增开关。关闭后不再绘制云、雨雪、雾、闪电与玻璃雨滴，只保留按太阳高度角连续插值的天空，并且不再联网取天气。
- **节气日历**：新增 `Utils/SolarTerm.swift`，提交 2026–2030 的二十四节气日期，提供 `term(on:)` 判节气与 `season(on:)` 划四季；窗口外年份复用最近表。

### 变更

- **飞书正文直接输入**：移除编辑按钮、局部编辑面板与普通保存确认，单击正文即可输入并保持排版；支持中文输入、原生撤销重做及粗体斜体快捷键。链接单击打开，Option+点击编辑文字。表格支持直接输入、拖动列宽和行高、增删行列、合并拆分、表头与框线粗细，尺寸结构修改可撤销；保留实际合并拓扑并修正多行内容的框线对齐。
- **供应商可以写 Claude Code 的并发上限**：每个模型新增「Subagent 并发数」与「Workflow 并发数」，分别写入 `settings.json` 的 `CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS`（正整数）与 `CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS`（1–256）。默认 20 / 30，旧配置解码时补上默认值，切供应商与「恢复官配」会一并清理。
- **第三方 OpenAI 接入在没有 Codex 供应商时回落 Claude Code**：优先跟随选中的或激活的 Codex 供应商；没有时使用 Claude Code 当前供应商的 OpenAI 兼容端点。该回落为只读，不写配置文件，并拒绝回环地址，以免请求回到本机代理。
- **连接器页改为常驻工具栏**：连接器与飞书文档的切换由父级浮层持有，两页共用同一条 36pt 工具栏。删除原页头卡片与按平台快选菜单，卡片从 210pt 收到 164pt，并移除卡上的 3D 倾斜与深度光环。
- **用量分析页两栏等高**：活动与结构卡片按列宽量高后取较高者，两张同时收敛；分析结果与图表输入在可取消的计算完成后一起上屏。
- **问候语与姓名统一为同行**：姓名排在问候语右侧同一基线，字号随问候语缩放，卡片宽度按两者之和收敛。
- **小时雨量改为曲线**：以细曲线与浅蓝渐变呈现每小时降水，缺失数据断开曲线并标破折号，小于 0.1 的雨量标为 `<0.1`。移除天空「预演」模式，控制只保留自动与手动。
- **「流量日志」新增「实时连接」档**：读取内核 `/connections`，给出每条连接的累计上传、下载与进程名。该档只列当前仍打开的连接，是快照而非账本。
- **「流量日志」改为分页**：三档最多渲染 200 行，环形缓冲从 10,000 降到 2,000，发布上限从 4 Hz 收到 1 Hz；暂停跟随或翻页时固定阅读快照。
- **用量页活动卡固定为热力图**：不再随周期在折线图与来源份额之间切换；来源份额改为常驻图例，悬停查看当天用量，点击下钻。
- **天气不再依赖代理**：取数顺序改为国内源优先（高德 → 中国天气网 → Open-Meteo → wttr.in），前两家命中 `GEOIP,CN → Direct`，不受 VPN 状态影响。
- **自建的供应商地址不再被 VPN 绕出国**：启动时读取本机配置的供应商表，将这些 host 同时写入系统代理绕过列表与规则链最前面的 `DOMAIN,<host>,DIRECT`。无法识别的 host 一律直连，只有七个必须走节点的域名被排除在外。
- **降低隐藏界面负载**：无可见窗口时暂停资源归因采样与风扇轮询，装饰、能源流、读数扫光、旋翼及问候时钟移出视口后暂停；JSON/SSE 与 Markdown 预览支持后台取消。合成 3 万事件解析中位耗时约 305 → 74 ms，进程峰值内存约 114 → 64 MiB。

### 修复

- **会话监控能跟上同时运行的多个 Claude Code workflow**：终态通知改为识别 Claude Code 2.1.287 写在 `attachment` 里的 `task-notification`，完成的 workflow 不再因为 90 秒无新日志而显示「状态未知」。父会话仍在运行工具时，活动行会列出每一个仍在运行的 workflow 与直接子 agent。
- **Codex 打开的回合不再被大段工具输出判成空闲**：末尾 512KB 内没有 `task_started` 时，向前补读最近的生命周期事件与工具名。活动行、弹窗、概览与小组件在回合进行中显示该工具，不再只显示模型名。
- **Cursor 子 agent 可展开查看**：会话页列出类型、名称与当前工具；父会话空闲而子 agent 仍在运行时，会话保持忙碌，活动行列出每一个正在运行的子 agent。
- **连接器的 Skill 启停改为仅移库**：三家客户端共用同一套可逆移库（`DisabledSkills/` + `registry.json`），不修改客户端配置文件；平台行只决定联动「当前平台」还是「全部平台」。同时修复移库后的符号链接无法还原的问题。
- **灵动岛通知新增「收起」按钮**：右上角新增一枚 ×，将灵动岛收回常态，不改变该会话的任何状态。
- **退出时不再把系统代理留在死端口上**：`applicationWillTerminate` 在停止内核之后同步清理系统代理并复原 DNS；启动路径改用异步变体，不再阻塞主线程。
- **TUN 的 DNS 快照按服务记录**：不再只保存第一个服务却在恢复时对所有服务写 `Empty`，配置了手工 DNS 的服务断开后不会静默掉回 DHCP。
- **主窗口不再每次都居中**：先按 `setFrameUsingName` 恢复位置，仅在从未保存过时居中。

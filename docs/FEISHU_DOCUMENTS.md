# 飞书文档工作区

连接器页顶部选择「飞书文档」，进入原生文档工作区。CLI 接口按官方 larksuite/cli 及本机 lark-cli 1.0.95 的 help / reference 核对。

## 使用

正式版使用已安装的官方 `lark-cli`，从 `~/.local/bin`、Homebrew、`/usr/local/bin`、Bun 及进程 PATH 查找。应用不安装 CLI、不自动升级、不保存令牌。首次在终端按官方说明安装 CLI 并配置飞书应用：

```bash
lark-cli config init --new --brand feishu
```

页面的「连接设置」可检查本机 CLI 登录状态、发起浏览器授权、取消等待及重新授权。授权只请求文档相关域（docs / drive / wiki / sheets / base / slides）；通过 `auth login --no-wait --json` 获取官方 HTTPS 链接，再由拥有该请求的后台子进程完成轮询，最长 10 分钟。关闭连接弹窗不取消登录，完成后自动加载文档。设备码与授权链接仅保留在内存，令牌写入由官方 CLI 管理。未安装 CLI 或未完成应用配置时提供官方指南与可复制配置命令，不自动创建应用或写入密钥。

进入页面先使用 `auth status --json` 判断用户身份；机器人身份不视为用户登录。返回页面时最多每 60 秒重新检查一次。账号或应用身份变化时取消旧请求并清空列表、正文及知识空间缓存；草稿保留但绑定原账号，不能误存到新账号。

官方说明：https://github.com/larksuite/cli

云空间列表、全文搜索、知识库、评论及成员操作需要各自的飞书开放平台权限。缺少知识库权限不影响云空间功能。连接设置页提供安装与授权说明，失败信息不回显 CLI 的原始 stderr 或凭据。

## 最近访问

默认进入「最近访问」，使用 `drive +search --opened-since ... --opened-until ... --sort open_time --as user` 获取当前用户打开过的文档，包含可访问的共享文档和知识库文档，不限于云空间根目录。入口支持最近 7 / 30 / 90 天，默认 30 天；关键词继续在所选访问时间范围内搜索。分页固定绝对时间边界，显式刷新时重新计算窗口。该列表来自飞书服务端搜索，并非本机应用自行记录的浏览历史；需要 `search:docs:read` 及用户授权。

## 功能范围

- 云空间文件夹、个人文档库、可访问知识空间与 Wiki 子节点浏览，面包屑返回。
- 全局文档搜索，300ms 防抖；文件类型筛选与显式分页。计数表示实际已加载资源数量，不使用服务端估算总数。
- Docx / Wiki 文档的 Markdown 排版预览、源码阅读与复制，支持直接单击输入及 Cmd+S 保存，无单独编辑按钮或编辑弹窗。表格支持拖动列宽、行高，右键增删行列、合并拆分及框线粗细调整。保存以首次修改时的 revision_id 为基准，失败保留内存草稿；服务端全文替换仍可能损失部分高级富文本和评论锚点，退出前需保存草稿。
- 云空间文档创建、文件夹创建、重命名、复制、移动与删除。Wiki 不提供 Drive 移动或删除，避免把 Wiki 节点 token 当作 Drive 资源 token。
- 文件上传、Word / Markdown 导入为在线 Docx；导出 PDF、Word、Markdown，用户选择目录，已有文件不覆盖。
- 分页读取评论、添加全文评论、解决 / 重新打开评论；卡片未包含的更多回复在飞书中查看。
- 查看协作者，按邮箱添加阅读 / 编辑权限、移除成员；权限变更再次确认，Wiki 新增权限仅作用于当前页，不发送消息通知。
- 分页历史版本列表及指定 revision 的只读阅读，不执行版本回滚。
- 其他文件类型支持资源信息和在飞书中打开，不在本界面编辑表格、Base 或幻灯片内部内容。

## 界面与风格

工作区嵌入 `ConnectorsView`，不增加主导航页面。连接器入口与飞书顶栏合并为单行；文档列表改为顶栏「文档」按钮展开的列表面板，支持搜索、文档库切换和分页；选择文档后自动收起，导航文件夹时保持展开。预览与编辑模块铺满页面，左侧只保留可收起的浮动文档目录。标题与正文相关操作集中在正文的紧凑工具栏，评论、协作者、历史、源码、打开、刷新、重命名、副本、移动、追加、三种导出和删除都使用显式图标按钮，不使用三点折叠菜单。窄窗口自动换行，按钮不被隐藏；鼠标停留提供说明，破坏性操作仍需确认。正文排版控制行宽，原生阅读与编辑都以文档为主体。

复用 `ActionButton`、`ActionIcon`、`InstrumentSearchField`、`panelCard`、`StandbyEmptyState` 与应用 Theme，跟随明暗主题及减少动态效果设置。类型筛选使用紧凑菜单，图标井统一尺寸；工作区标记为静态矢量图形。

## 编辑与新建

草稿的标题、源码、复制、丢弃、返回和保存合并为一行，尽量保留正文高度。排版正文直接使用原生文本控件输入，不切换到编辑面板；整篇 Markdown 源码仍可通过工具栏显式打开。首次实际修改后固定版本号，读取刷新不会覆盖草稿；切换文档或离开连接器仍可从顶栏「草稿」恢复。保存失败或冲突时保留输入，不自动覆盖云端内容。可复制草稿、明确丢弃后重新读取，或在飞书中编辑富文本。

「新建文档」使用同一区域填写标题与正文，展示目标目录，成功后直接打开返回的文档。最近访问入口新建的目标为云空间根目录。最多保留 8 份、合计 8MB 正文草稿；满额时提示处理已有草稿，不静默淘汰。草稿仅在当前应用进程内保留，退出前需保存或复制；界面始终标明尚未保存到飞书。开发版可体验编辑/新建草稿，云端保存和登录入口仍受版本闸保护。

## 结构化阅读与目录

共享的原生 Markdown 渲染器增加有界 HTML 片段解析：支持飞书导出的 HTML 表格、表格单元格中的 pre/code、换行、实体字符、粗体和链接，也支持任务列表、转义竖线、不同长度的代码围栏及 Setext 标题。合并单元格展开为对齐的逻辑列，延续行标记为 ↳，跨列延续标记为 ↔；宽表可水平滚动。代码字面量保留标签，不把代码内容解释成 HTML。

打开正文时优先显示左侧浮动目录，按照 H1–H6 层级缩进并编号，点击条目跳到对应标题；相同标题使用不同块锚点。标题旁提供淡色层级标记，目录不占顶部固定高度，收起后正文扩展到完整宽度；编辑与预览共享目录面板，编辑时点击标题跳到原始 Markdown 对应位置，跳转不会覆盖草稿或撤销栈。目录后台更新并排除代码块中的伪标题。图片、白板、表格嵌入、音视频等需要飞书运行环境的资源显示说明卡片，使用正文工具栏打开原文；不直接打印 token 或原始标签，不自动下载受保护资源。

解析在后台执行，无 WebView、JavaScript、CSS 或外部实体加载；HTML 片段最多 20,000 个标签、64 层嵌套。超过原有 512KB 排版上限的正文保持原生源码阅读，可在飞书中查看原始富文本。

## 性能与隔离

原生 List 复用文档行。512KB 内的正文复用现有 Markdown 组件，在后台解析并懒加载段落；更大的正文自动使用 NSTextView 非连续布局，也可手动切换源码；不为每行文本建立 SwiftUI 节点。CLI 与 JSON 解码在后台执行，stdout / stderr 同时排空，保留输出上限 16MiB，普通请求超时 90 秒，用户明确发起的登录轮询超时 600 秒。导航及正文请求支持取消和请求身份校验，取消只终止该请求拥有的子进程。内存 LRU 最多保留 12 组列表、8 篇正文，新鲜期 60 秒；命中后直接显示，过期时保留缓存并后台更新，失败时继续提供缓存阅读并标明未更新。读取不延长新鲜期，淘汰逐项进行；最近访问列表缓存复用原分页窗口。写入前取消旧读取并清除相关列表/正文缓存，评论、成员及导出不清空正文缓存；账号变化完整清空云端缓存。不在磁盘缓存云文档。

开发版仅显示示例数据。即使只读 CLI 命令也可能刷新共享令牌，因此在真实进程启动入口用 `BuildChannel.allowsSystemIntegration` 拒绝所有真实 CLI 请求；写入入口再次拒绝开发版操作。不读取或复制正式 CLI 凭据、不修改系统代理、不请求系统权限，不启动 VPN。网络代理由 CLI 进程的现有环境配置决定，页面不修改系统代理或外部客户端配置。

## 验证

```bash
make test TEST=feishu-documents
make test
make build
make release
```

回归测试直接编译生产 JSON 解析、请求构建和状态模型，验证 Drive / 搜索 / Wiki 返回、最近访问分页参数、LRU 淘汰与固定新鲜期、链接边界、凭据安全错误、开发版拒绝执行以及自有模拟子进程取消。正式版模型通过临时模拟 CLI 验证登录完成/取消、账号隔离、缓存命中与过期刷新、失败后保留正文、分页去重、版本号保存、冲突保留草稿以及新建后自动打开。测试不访问飞书服务。构建和签名验证不能替代正式版账号的云端读写验证；后者需用户在明确授权的资源上手工执行。

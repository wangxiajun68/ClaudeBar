# 桌面木鱼

在 **设置 → 通用 → 桌面木鱼** 打开「显示悬浮木鱼」。开发版和正式版各自保存开关、位置和记录。

桌面上没有按钮、工具栏或右键菜单。暖杏色木鱼、可可色轮廓、连续回纹开口与木槌直接悬浮在桌面；外围透明空间可点击穿透。

- **点击敲击**：松手增加一份功德，木鱼压缩回弹、木槌落击，同时浮出「功德 +1」和「Token +1」。它们是本地趣味反馈，不改变真实模型 Token 用量。
- **直接拖动**：移动至少 5 个原生点后进入原生窗口拖动，不会误计一次敲击。位置自动保存，屏幕移除或分辨率变化后会回到可见范围。Option 拖动兼容旧习惯。
- 悬停、敲击期间或自动运行时，木鱼下方显示只读计数。今日计数保持独立；第二行显示累计、连击、彩蛋或自动节奏。计数不是按钮，不截获桌面点击。
- 音效、音量、自动敲击、0.5 / 1 / 2 / 3 秒间隔、三档大小、清空记录和隐藏，统一在应用设置中调整。清空记录需要确认。
- 键盘辅助操作保留：木鱼获得焦点后空格敲击、Esc 暂停。没有全局键盘监听。

自动敲击只属于当前会话。隐藏、休眠、屏幕休眠、退出和性能模式会停止计时器与音效；唤醒、重新显示和重启不会自行恢复。音频在内存生成，不请求麦克风权限，声音不可用时仍可计数。

手动间隔不超过 0.55 秒形成连击，8 / 16 / 32 连击和累计 108 / 1024 / 4096 次有文案彩蛋，每种彩蛋有独立的八秒冷却。自动敲击不形成连击或消耗当天手动首击彩蛋。所有敲击仍只增加一份功德。

## 动效与性能

器物和浮字由单个 Canvas 绘制；有反馈时才启动可取消的异步刷新任务，以 16.67ms 的绝对截止时间调度，目标 60fps；错过的帧直接跳过，避免追赶造成突发负载，最后一次敲击后约 1.42 秒停止。静置不运行绘图循环。两组双行浮字完整播放；更早的浮字沿原轨迹用 180ms 平滑淡出，后续敲击不会重置其位置或淡出时钟。淡出尾迹池上限为 24 组，八连击起每组才显示三颗粒子，粒子随所属浮字淡出。减少动态效果时保留最新一组定点反馈及旧组淡出尾迹，关闭器物变形及粒子。

按压用 80ms 缓出，快速松手从当前形变继续回到原位。连续落击叠加仍在回弹的共鸣响应，新响应从零开始，避免器物突然跳回初始状态。初次显示时解析并测量中英文字形；声音开启且音量大于零时，波形生成、四个音频播放器的创建与预备均在专用串行队列提前执行。连点复用播放器时使用暂停与归零，保留准备状态；重新开启声音时复用播放器并再次预备。播放不阻塞主线程；静音、隐藏、休眠与退出即时使待播放请求及延迟回调失效，并在音频队列释放播放资源。

绘制和命中共享外形。命中描边提前缓存；指针在窗口外时只做矩形判断，不分配路径、不发布悬停状态。仍保留鼠标事件监听以支持异形窗口的点击穿透。窗口尺寸由控制器管理，NSHostingView 不在动画中重新协商固有尺寸。

尺寸缩放为 0.36 / 0.46 / 0.56；标准本体约 90pt 宽，比上一版缩小约 36%；窗口为 `260 × scale` 宽、`78 + 200 × scale` 高，顶部 36pt 透明留白用于反馈，底部计数高 36pt。文字保持原生字号。

## 开发验证

```bash
make test TEST=wooden-fish
python3 Tools/render-wooden-fish-preview.py --hover
python3 Tools/render-wooden-fish-preview.py --auto
python3 Tools/render-wooden-fish-preview.py --motion --pointer
python3 Tools/render-wooden-fish-preview.py --motion --reduced-motion
python3 Tools/render-wooden-fish-preview.py --exercise
python3 Tools/render-wooden-fish-preview.py --measure
```

回归使用临时偏好域，验证生产计数、命中、点击／拖动状态机、反馈容量、连续淡出、形变连续性、运动边界和音频波形。阻塞的模拟音频工厂验证初始化在后台，停止后排队播放和迟到回调失效；它不播放真实声音。`--motion --pointer` 记录首次按压、快速按下／释放和回到闲置后再次点击。`--exercise` 使用独立静音窗口验证生产控制器的点击释放、取消误触、自动节奏、Escape 与隐藏释放，不启动完整应用。

`--measure` 会短暂显示一个独立静音生产视图：测量三秒静置、三秒每秒十二次敲击、反馈结束后的三秒静置及十万次命中判断的进程 CPU 时间，同时报告首次反馈重绘延迟、绘制频率、95% 帧间隔和超过 25ms 的间隔数。它不是整个应用或 VPN 的性能测试；机器、系统版本及同时运行的工作会影响结果。`--reduced-motion` 只改变预览夹具的环境绑定，不修改系统偏好。

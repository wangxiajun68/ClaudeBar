# 桌面木鱼

在 **设置 → 通用 → 桌面木鱼** 打开「显示悬浮木鱼」。默认关闭，开发版和正式版各自保存开关与记录。

木鱼以原生矢量路径绘制，实心玉绿本体、青碧棒柄与暖金棒头均使用完全不透明的纯色填充，外围背景透明。静置时只显示紧凑木鱼、敲棒和底部粗弧；点击器物敲击，外围透明区域可以点击穿透。

三档器物缩放为 0.60／0.72／0.88，窗口占位分别为 156×190、187.2×214、228.8×246pt。标准本体线性尺寸较原版缩小 28%，面积约减半；11pt 计数与 10pt「Token」与 18pt「+1」保持原生尺寸。青碧主轮廓配灰绿弧线、珊瑚色开口与实心眼、暖金色圆棒头，深色主题使用对应的明亮配色。圆润椭圆本体采用约 1.618:1 的黄金比例，绘图使用等比投影；眼睛位置、棒头与柄的可见厚度关系、底部弧线宽度也沿用黄金比例。16／10／8 的主次粗线配圆端点与圆转角，窄反差描边沿相同路径提高壁纸上的辨识度。器物使用纯色填充，无渐变、纹理、阴影或卡片。

- 点击木鱼、敲棒的实心本体或轮廓，以及底部粗弧，播放短促的木质音效；敲棒抬起、落击并回弹，每次生成独立的一条「Token +1」与六颗金色／青色／紫色小菱形；获得键盘焦点后也可按空格，Esc 可暂停自动敲击并复位连击。Esc 只作用于木鱼窗口。
- 木鱼没有按钮栏。悬停仅轻微提亮器物，并显示今日与累计功德；按住 Option（⌥）拖动器物可移动，位置会保存。
- 右键器物打开原生菜单，提供静音、自动启停、0.5、1、2、3 秒节奏、三种大小、需要确认的记录清空与隐藏。悬停轻微提亮器物，按压有短促缩放反馈。
- 音量在设置中调整。今日功德随本机日期归零，累计、音量、节奏、大小和位置保留。
- 移除外接屏幕或改变分辨率后，木鱼回到可见屏幕范围。

自动敲击仅在本次会话中运行。隐藏、休眠、屏幕休眠、退出和性能模式会停止计时器与音效。重新显示、唤醒或下次启动不会自行开始敲击。性能模式恢复桌面后，只恢复已保存的显示开关。

音效在内存生成，无网络、额外音频文件或麦克风权限。无法播放时显示提示图标，计数仍可使用。

「Token +1」仅是敲击趣味反馈，不改变真实模型 Token 用量，每次敲击照常增加一份功德。快速敲击最多保留八条独立浮字，起点、角度、射程、曲率与速度各有变化，向左右和上方发散，不按固定列或层排列，后来的词条不会替换仍在显示的旧词条。同一帧的连续敲击也会补齐最近八次反馈。词条没有黑底或胶囊：小号 Token 与更大的斜体 +1 组成透明浮字，细描边沿字形，+1 下方短弧逐渐收短，文字沿各自弯曲轨迹轻弹飞散。普通词条为青碧／浅青，八连击起或彩蛋触发时为暖金色。敲棒动作约 0.46 秒，反馈动画约 1.35 秒，每组约 1.42 秒自动清除；六颗彩色粒子可叠加，最多保留八组。

手动敲击间隔不超过 0.55 秒形成连击：八连击显示「8 连击 · 进入心流」，十六连击显示「There is no spoon.」，三十二连击显示「烦恼 Cache Miss」。手动敲击使累计恰好到达 108、1024、4096 时，分别显示「108 · 心静如水」「1024 · Hello, world.」「4096 · Inner peace」，同次优先显示累计里程碑。每种彩蛋各有八秒冷却。下方计数胶囊会暂时显示连击或彩蛋，随后恢复今日与累计计数。

「今日开敲」是本次启动中当天第一次手动敲击；自动敲击不消耗手动首击、不形成连击，也不触发彩蛋。暂停、隐藏、休眠和性能模式复位连击链；彩蛋不额外增加功德、Token 或音效。

开启系统「减少动态效果」后，器物与敲棒保持静止，取消按压缩放、浮字弧线与所有粒子，仅最新一条「Token +1」在固定位置渐隐；计数、音效与彩蛋文案仍可使用。反馈不会扩大窗口或鼠标捕获范围，器物命中继续共用绘图几何，上方透明留白不拦截鼠标。

## 开发验证

```bash
make test TEST=wooden-fish
python3 Tools/render-wooden-fish-preview.py
python3 Tools/render-wooden-fish-preview.py --hover
python3 Tools/render-wooden-fish-preview.py --motion
python3 Tools/render-wooden-fish-preview.py --motion --hover --small
python3 Tools/render-wooden-fish-preview.py --motion --hover --reduced-motion
python3 Tools/render-wooden-fish-preview.py --exercise
```

回归编译并执行生产计数、音频波形、位置／鼠标命中、粒子运动与反馈池容量逻辑，使用临时偏好域，不启动应用或播放声音。预览生成三种大小、两种配色的生产视图截图；`--motion` 捕获实际生产视图的单次及连续敲击动画帧。`--reduced-motion` 在预览夹具中将只读的减少动态效果绑定注入为开启，不修改系统设置。`--exercise` 创建独立的静音木鱼夹具窗口，验证实际控制器的手动敲击、自动节奏替换、窗口内原生 Escape、隐藏与性能模式释放，不读取用户偏好或启动完整应用。

# 桌面木鱼

在 **设置 → 通用 → 桌面木鱼** 打开「显示悬浮木鱼」。默认关闭，开发版和正式版各自保存开关与记录。

木鱼以原生矢量路径绘制，背景透明。静置时只显示木鱼、敲棒和垫子，周围透明区域可以点击穿透。

三档器物缩放为 0.60／0.72／0.88，窗口占位分别为 156×190、187.2×214、228.8×246pt。标准本体线性尺寸较原版缩小 28%，面积约减半；26pt 工具按钮、11pt 计数与 12pt「Token +1」保持原生尺寸。木材用柔和高光、疏密曲纹、浅木节和细雕刻口表现体积，玉绿色垫子收为带细缝线的薄椭圆，敲棒保留弧形高光。

- 点击木鱼、敲棒或垫子，播放短促的木质音效；敲棒抬起、落击并回弹，每次一条青色「Token +1」与六颗金色／青色／紫色小菱形向上发散；获得键盘焦点后也可按空格。
- 悬停显示工具，从左到右是拖动把手、静音、自动敲击、更多选项和隐藏。工具间距 4pt，总宽 146pt，小巧尺寸仍完整适配；更多选项保留原生菜单。下方显示今日与累计功德。
- 更多选项提供 0.5、1、2、3 秒节奏，三种大小，以及需要确认的记录清空。
- 音量在设置中调整。今日功德随本机日期归零，累计、音量、节奏、大小和位置保留。
- 移除外接屏幕或改变分辨率后，木鱼回到可见屏幕范围。

自动敲击仅在本次会话中运行。隐藏、休眠、屏幕休眠、退出和性能模式会停止计时器与音效。重新显示、唤醒或下次启动不会自行开始敲击。性能模式恢复桌面后，只恢复已保存的显示开关。

音效在内存生成，无网络、额外音频文件或麦克风权限。无法播放时显示提示图标，计数仍可使用。

「Token +1」仅是敲击趣味反馈，不改变真实模型 Token 用量，每次敲击照常增加功德计数。敲棒动作约 0.46 秒，发散反馈约 0.85 秒，每组约 0.92 秒自动清除；六颗彩色粒子可叠加，最多保留八组。「Token +1」只显示最近一次敲击的一条，沿中间轨迹上移淡出，新敲击取代旧文字，快速敲击时文字不会互相覆盖。只有器物和反馈轨迹随大小选项缩放。开启系统「减少动态效果」后，器物保持静止，仅最新一条「Token +1」静止淡入淡出，计数与音效仍可使用。反馈不会扩大窗口或鼠标捕获范围，工具与器物的命中继续共用绘图几何。

## 开发验证

```bash
make test TEST=wooden-fish
python3 Tools/render-wooden-fish-preview.py
python3 Tools/render-wooden-fish-preview.py --hover
python3 Tools/render-wooden-fish-preview.py --motion
python3 Tools/render-wooden-fish-preview.py --exercise
```

回归编译并执行生产计数、音频波形、位置／鼠标命中、粒子运动与反馈池容量逻辑，使用临时偏好域，不启动应用或播放声音。预览生成三种大小、两种配色的生产视图截图；`--motion` 捕获实际生产视图的单次及连续敲击动画帧。`--exercise` 创建独立的静音木鱼夹具窗口，验证实际控制器的手动敲击、自动节奏替换、隐藏与性能模式释放，不读取用户偏好或启动完整应用。

# 桌面木鱼

在 **设置 → 通用 → 桌面木鱼** 打开「显示悬浮木鱼」。默认关闭，开发版和正式版各自保存开关与记录。

桌面上只有原生矢量木鱼与敲棒，没有可见按钮、工具栏或右键菜单。暖杏色的不对称共鸣腔配可可色细轮廓，一笔连续内卷刻槽连接开口，暖木色敲棒和短底弧完成器物轮廓。外围背景透明，静置没有循环动画。

- **点击敲击**：按下器物并在原处松开才计数、发声；鼠标移动未满 5pt 且松开仍位于器物内才算点击。
- **直接拖动**：按住器物移动至少 5pt 即开始拖动，不需要修饰键，也不会误增功德；位置会保存。Option 拖动仍兼容。
- **设置集中管理**：音效开关、音量、自动启停、0.5／1／2／3 秒节奏、三档大小、清空记录与隐藏都在应用设置中。清空记录需要确认；关闭「显示悬浮木鱼」即可隐藏。
- **键盘与辅助功能**：木鱼获得焦点后，空格敲击，Esc 暂停自动敲击并复位连击；Esc 只作用于木鱼窗口。器物保留敲击辅助功能名称与操作提示。
- **按需计数**：悬停、敲击反馈期间或自动敲击时显示今日与累计／节奏／连击提示。计数仅供阅读；计数区及外围透明区域均可点击穿透。移除外接屏幕或改变分辨率后，器物回到可见范围。

三档缩放为 0.60／0.72／0.88，窗口占位分别为 156×198、187.2×222、228.8×254pt。器物等比缩放；今日数字为原生 13pt，辅助文字为 10pt，浮字「功德」为 10pt、「+1」为 18pt，不随器物缩小。窗口占位不等于可见背景。

每次敲击增加一份功德，触发短促的本体回弹、敲棒落击与「功德 +1」浮字；这不会改变真实模型 Token 用量。最多同时保留四组反馈，新增超限时移除最早一组。各组沿独立弧线飞散，约 1.35 秒完成动画、1.42 秒清除；只有八连击及以上每组出现三颗暖色粒子，普通点击和自动敲击没有粒子。静置不运行反馈动画。鼠标命中复用缓存的路径，窗口外的指针移动先做矩形排除；这些是代码层面的负载约束，不代表已测得 CPU 或能耗数值。

手动敲击间隔不超过 0.55 秒形成连击：八连击显示「8 连击 · 进入心流」，十六连击显示「There is no spoon.」，三十二连击显示「烦恼 Cache Miss」。手动敲击使累计恰好到达 108、1024、4096 时，分别显示「108 · 心静如水」「1024 · Hello, world.」「4096 · Inner peace」，同次优先显示累计里程碑。每种彩蛋各有八秒冷却。

「今日开敲」是本次启动中当天第一次手动敲击；自动敲击不消耗手动首击、不形成连击，也不触发彩蛋。今日记录随本机日期归零；累计、音量、节奏、大小和位置保留。自动敲击只属于本次会话，隐藏、休眠、屏幕休眠、退出和性能模式会停止计时器与音效，并复位连击。重新显示、唤醒或下次启动不会自行开始敲击；性能模式结束只恢复已保存的显示开关。

音效在内存生成，无网络、额外音频文件或麦克风权限。无法播放时，计数提示区显示「音效不可用 · 请检查输出」，计数仍有效。开启系统「减少动态效果」后，器物与敲棒静止，取消按压变换、浮字弧线与粒子，仅最新一条「功德 +1」固定位置渐隐；计数、音效与彩蛋文案仍可使用。

## 开发验证

```bash
make test TEST=wooden-fish
python3 Tools/render-wooden-fish-preview.py
python3 Tools/render-wooden-fish-preview.py --hover
python3 Tools/render-wooden-fish-preview.py --motion
python3 Tools/render-wooden-fish-preview.py --motion --hover --small
python3 Tools/render-wooden-fish-preview.py --motion --hover --reduced-motion
python3 Tools/render-wooden-fish-preview.py --exercise
```

回归与预览应使用临时偏好域，不修改真实用户数据、不启动 VPN。回归直接验证生产计数、音频波形、位置／形状命中、点击与拖动阈值、反馈轨迹和容量。预览用于查看三档尺寸、浅深配色、实际生产视图动画及减少动态效果；`--exercise` 使用独立静音夹具验证控制器生命周期。原生 SwiftUI／AppKit 界面不使用 HTML 检测器。

以上是验证入口，不是本版已通过的结果声明。真实桌面拖动、音频输出与 CPU／能耗需要分别验证，编译或静态预览不能代替这些结果。

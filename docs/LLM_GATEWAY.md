# Auto 免费模型网关

入口：**模型 → 自动网关**。供应商目录和 Claude Code / Codex 的激活流程保持独立。

与 New API 的能力对比、当前已补齐项、未实现项和可复测性能见 [NEW_API_COMPARISON.md](NEW_API_COMPARISON.md)。

Auto 在未指定难度时，通过本地规则判断用户任务的类型和难度，再结合模型池能力与运行健康状态选择模型。规则基线不增加外部模型调用；语义分类器、任务质量评测与会话黏性仍属于后续设计。Cursor 等方案的调研见 [模型任务路由](technical/llm-model-routing.md)。

## 接入

1. 在供应商目录保存连接凭据。已有 Claude Code / Codex 供应商都能作为候选；Claude Code 的地址使用现有 `ProviderBridge` 转换到 OpenAI 兼容接口。
2. 在「从已有供应商提交」选择供应商和模型，确认免费资格、上下文长度、工具／图片／JSON 能力，加入 Auto 池。网关使用该供应商的 Chat Completions 接口，供应商本身需要支持此接口。
3. 打开 Auto 和设置里的本地代理。第三方客户端填写设置页所示 Base URL、本机 API Key，以及模型名 `auto`（也接受 `claudebar/auto`）。Anthropic 客户端使用同一监听地址的 `/v1/messages`。

默认只接管第三方的 Auto 请求。显式模型名继续走原上游，Claude Code / Codex 请求仍走各自配置。可选「接管全部第三方请求」会覆盖第三方显式模型名。网关不开启时 Auto 返回明确错误，避免落到其他上游。

「记录第三方流量」决定是否在流量页保留请求正文；每次备用尝试会显示实际供应商和模型。本次运行最近 40 次路由尝试的状态、模型与延迟始终可在网关页查看，不包含请求正文、密钥或账户信息。

## 按任务难度路由

客户端只需设置 `model: auto`。未传难度时，网关读取最近的有效用户目标，通过本地规则判断 low / medium / high；无法明确判断时保守采用 medium。顶层字段 `task_difficulty` 保留为可选覆盖，取值为 `low`、`medium`、`high`，传入后优先遵守客户端指定档位。Chat Completions、Responses 和 Anthropic Messages 使用相同字段；无效取值返回 HTTP 400。它只用于网关选模型，在发给上游前删除，不修改上游的推理强度参数。

```json
{
  "model": "auto",
  "messages": [{"role": "user", "content": "排查偶发死锁"}]
}
```

规则覆盖问候／连接检查、提取／翻译／转换、常规编码／写作，以及复杂排错、系统设计与多步推理。长原文的转换任务不会仅因长度或原文包含复杂术语升档；系统提示和工具输出不作为任务指令。“继续”与工具续轮参考已有用户目标，自动判断的工具任务至少采用 medium。新用户目标重新判断。当前规则以常见中文／英文指令为主，不是训练过的语义分类器，不提供未经评测的准确率保证。

自动判断的档位没有兼容模型时，可依次升到更高档位，绝不自动降档；显式指定难度始终严格匹配。匹配档位已有模型但正在冷却时仍返回冷却错误，不靠跨档位切换规避冷却。状态页显示任务类型、实际档位、规则／客户端指定／兜底来源，以及升档与选模原因，不保存用户原文。

模型池每个条目可直接勾选低／中／高难度，可多选；手动加入时也能设置。新模型和旧配置中未保存难度的模型默认承接所有档位，随后可按需要收窄，例如轻量模型只承接 low、强模型只承接 medium / high。目录刷新保留手动设置。

网关先确定可承接任务的难度档位，再筛选工具、图片、JSON、上下文和冷却状态，最后按所选策略排序。备用切换仍留在该难度内；没有匹配模型返回 400，匹配模型都在冷却时返回 503，不会自动降到其他档位。网关状态记录每次尝试的判断来源、难度和选择原因。显式模型名未被网关接管时仍走原路由。

## 模型池与可用性

供应商页面的已配置预设卡片、自定义卡片和「当前激活」卡片提供「加入 Auto 池」。可从该卡片的多个已保存配置中批量选择模型，复用已有供应商 UUID 和凭据；Claude Code 配置沿用现有桥接转换到对应兼容入口。导入不激活供应商、不启用网关、不复制密钥。需使用远端 HTTPS OpenAI 兼容 Chat 接口并确认免费资格；OpenRouter 还须在有效免费目录中。纯客户端官方登录卡片没有可复用的 API 凭据，不提供此入口。

导入器支持搜索、全选、上下文核对及「档位与能力」设置。选择前检查连接，分别说明 HTTP、缺少 Key、本机接口或地址格式问题；不可导入项不能勾选，并可通过「修改供应商配置」直接回到原配置。未配置的上下文暂用 32,768 并明确提示；其他供应商的工具、图片和 JSON 能力由用户声明，初始关闭，OpenRouter 使用免费目录中的上下文和能力。免费确认、设置和提交固定在底部，不必滚到长模型列表末尾。重复导入保留原有启用状态、能力和档位；供应商被删除、模型改名、目录过期或超过 200 个成员时整批拒绝，保存失败保留选择并显示原因。

「发现模型」使用自适应紧凑网格，每张卡保留名称、ID、上下文、能力和加入状态。名称及 ID 单行截断，悬停可查看完整内容，ID 仍可选择复制；列数随可用宽度变化，目录采用懒加载。

- 均衡轮转：优先失败较少、最近较少使用的模型。
- 池内顺序：按从上到下的模型优先级选择，可在模型菜单上下移动。
- 低延迟优先：使用已观测的首次有效输出耗时，尚未测量的模型先获得试用机会。
- 供应商加权：按配置权重分配请求，同一供应商下的多个模型共享权重和额度。
- 依据请求过滤工具、图片、结构化 JSON 和上下文容量。上下文使用保守的本地估算，不能替代模型的真实 tokenizer。
- 最多尝试 1–5 个模型；全局和供应商并发独立控制，满载进入有界队列。每分钟额度计入备用尝试，额度用完仍立即返回 429；队列只等待并发空位。
- 429 按供应商共享冷却，缺少 `Retry-After` 时为 60 秒；支持秒数及 HTTP 日期，范围 1 秒至一小时。404 / 410 冷却 30 分钟；网络和服务端故障指数退避。401 / 402 / 403 暂停对应供应商五分钟，可继续选择另一供应商。冷却后同一故障范围只放行一个恢复探测。
- HTTP 成功但首个 SSE 帧报错仍可切换。首次有效输出开始后不再重放请求，断流会明确结束为错误。取消不会记作模型故障。
- 「未测试」表示尚无成功请求，目录发现不代表已通过推理测试。模型列表的「测试」和拓扑详情的「测试模型」会向选中的模型发送一次 `Reply with OK.` 文本请求，最多 128 输出 tokens；成功必须收到非空 Chat Completions 文本输出。测试通过只验证连接、鉴权和基础文本输出，不验证工具、图片或 JSON 能力。
- 手动测试只使用指定模型，不切换备用模型、不修改客户端配置；Auto 关闭时仍可测试已启用且已分配档位的模型。测试仍受免费目录有效期、OpenRouter 零价格约束、并发、排队、每分钟额度和冷却限制，一次只发起一个 UI 测试。最多等待 20 秒上游响应（另加网关排队时间），可点「取消测试」；运行时的健康状态和真实路由动画同步更新。测试结果不保留提示词、输出或供应商错误正文；模型的健康统计仅在本次应用运行中有效。
- 成功、失败、冷却和缺少凭据都有独立状态。
- 修改或删除供应商会更新运行时引用，不复制凭据、不修改供应商的激活状态。手动模型可停用、移除和编辑能力。

其他平台的永久免费、赠送额度、试用资格由用户确认。网关无法为这些平台验证账单规则或保证超出免费额度后不收费；应在供应商账户关闭超额付费或设置额度限制。

## 供应商并发与队列

入口：**自动网关 → 设置 → 并发与队列／供应商并发**。设置按已保存的供应商配置 UUID 隔离，同一配置下所有模型共享并发额度；同一品牌的不同连接配置分别计数。可单独修改池内供应商的并发上限，也可恢复默认值。页面显示全局及各供应商的处理／排队数量。

| 设置 | 默认 | 范围 |
| --- | --- | --- |
| 全局并发 | 4 | 1–64 |
| 供应商默认并发 | 2 | 1–64，可按配置覆盖 |
| 等待队列容量 | 32 | 0–1024；0 表示满载不等待 |
| 每供应商队列容量 | 8 | 1–1024，仍受全局容量限制 |
| 最长排队时间 | 30 秒 | 1–120 秒 |
| 等待请求正文合计 | 64 MiB | 固定保护上限 |
| 全局每分钟请求 | 20 | 1–6000 |
| 每供应商每分钟请求 | 不单独限制 | 可设 1–6000，始终受全局额度约束 |
| 每供应商估算 TPM | 不限制 | 可设 1–10,000,000；输入估算量加预留输出量计入最近 60 秒，备用尝试重新扣额 |
| 首次有效输出 | 20 秒 | 1–120 秒 |
| 上游无数据期限 | 30 秒 | 1–300 秒 |
| 重试预算 | 60 秒 | 1–300 秒 |
| 请求总时长 | 180 秒 | 1–1800 秒，开始执行后计时，包含备用等待 |

首帧、重试和总时长使用独立期限；SSE 注释心跳不能延长首帧或请求总时长。首帧期限不能大于总时长。调高并发不会增加供应商的账户额度，也不是实际吞吐量保证。

额度由网关 actor 原子预留，同一供应商的不同模型及备用尝试不能绕开上限。队列按到达顺序选择最早可执行的请求；某个供应商满载时，其他兼容供应商有空位便可接手，独立供应商的请求不被队首阻塞。等待中的备用请求也会重新检查剩余候选，选择刚获得空位的兼容供应商。实际尝试数始终受「最多尝试」限制，跳过繁忙或冷却候选不消耗尝试次数。

排队不占全局／供应商执行额度，不消耗每分钟请求额度，也不制造路由图上的连接或输出动画。流式请求从预留额度起，直到流式完成或断开才释放；收到响应头不算完成。失败转入备用前取消原上游并释放原额度；备用等待期间释放全局执行额度，保留请求身份。首次有效输出之后仍不重试。

队列满、每供应商队列满或正文保护上限耗尽，返回 HTTP 429，错误码 `gateway_queue_full`；等待超时返回 HTTP 504，错误码 `gateway_queue_timeout`；关闭排队后满载返回 429／`gateway_busy`。这些响应带 `Retry-After: 1`，并发等待不记录为模型故障。每分钟请求或估算 token 额度耗尽返回 429／`gateway_rate_limited` 和保守的 `Retry-After: 60`。TPM 是调度保护值，不是供应商实际结算用量；超过单供应商预算的单次请求不会在队列中无限等待。

客户端关闭连接会立即撤销等待；流式客户端断开会取消上游并释放额度。取消、超时、备用切换和收尾都只释放自己持有的额度。保存网关设置、修改供应商引用或停用网关会明确中止旧配置下的等待；正在运行的转发仍保留额度直到结束，降低上限不会让已有额度凭空消失。退出应用取消等待任务和定时器。队列仅保存在内存，重启不重放请求；旧版模型池自动补入上述默认值，原配置和凭据引用保持不变。

## OpenRouter 发现

使用官方 [`GET /api/v1/models`](https://openrouter.ai/docs/api/api-reference/models/get-models)。默认每六小时发现一次，可改为一小时或一天；默认手动选择加入，自动加入为显式选项。目录可匿名发现，实际推理需要选择已有的 OpenRouter API Key。

只接纳有文本输出、上下文长度有效，且所有已公布价格（至少包含输入与输出）均为零的模型。`:free` 后缀本身不作为免费证据。收费变化、下架或者目录超过 48 小时未更新时，该 OpenRouter 模型不再参与路由；发现失败保留上次成功目录。推理额外设置 `provider.max_price` 的输入、输出、请求、图片、音频维度为零，删除客户端传来的模型回退列表和付费插件。

OpenRouter 的[免费路由说明](https://openrouter.ai/docs/guides/routing/routers/free-router)和[额度说明](https://openrouter.ai/docs/api_reference/limits)明确指出可用性、能力和限流受平台规则影响。跨模型切换不能绕过账户总额度，也不保证任一免费模型始终在线。

OpenRouter 使用 `require_parameters` 避免静默丢弃工具或 JSON 参数，且不发送已废弃的 `stream_options`；平台会[自动返回用量](https://github.com/OpenRouterTeam/docs/blob/main/cookbook/administration/usage-accounting.mdx)。其他 OpenAI 兼容上游仍请求流式用量。

## 协议与边界

支持 OpenAI Chat Completions（JSON / SSE）、Responses（JSON / SSE）与 Anthropic Messages（JSON / SSE）。Responses / Anthropic 使用现有协议适配器转到 Chat Completions。支持工具历史、工具调用和图片；Chat 还支持 `input_audio`、`video_url`、原生 PDF `file` 以及 `modalities` 指定的音频/图片输出。Responses 支持音频、视频和文件输入转换，Anthropic 支持 PDF 文档输入；不支持的输出协议组合和服务端内建工具明确报错，不静默丢弃媒体。Responses 的 `previous_response_id` / `conversation` 不参与无状态跨供应商路由，客户端须携带完整历史。Anthropic `count_tokens` 返回本地保守估算，不发送推理请求或消耗网关额度。

独立接口支持 `POST /v1/images/generations`（单张 JSON）、`POST /v1/audio/speech`（二进制分块返回）、`POST /v1/embeddings`（字符串/字符串数组）、`POST /v1/rerank`（字符串 query/documents）。客户端使用 `model: auto`，手动供应商须在模型能力中启用对应 API；纯图像、语音、嵌入等模型还应关闭“支持 Chat Completions”，避免被普通聊天选中。这些接口共用调度和期限；OpenRouter 的 Chat 免费目录不能证明独立 API 免费，因此不接受它作为这些端点的候选。嵌入固定池内首个兼容模型，仅允许同名模型的跨供应商备用；改动嵌入模型配置前需自行迁移已有向量索引。

音频为 base64 内容与格式；图片/视频/PDF 接受 HTTPS URL 或匹配 MIME 的 base64 data URI，网关不读取本机文件或下载 URL。单个内联媒体最多 16 MiB 编码数据。PDF 在 OpenRouter 固定原生处理，禁止默认付费 OCR。加入 Auto 池时可读取供应商 `/models` 明确声明的逐模型输入／输出模态，并显式同步已入池成员；只返回模型 ID 的供应商显示“其他模态待核实”，需按模型手动声明。网关不会仅因供应商支持多模态接口就假定其每个模型支持所有模态。手动“测试模型”仍只是 Chat 文本测试，不能认证多模态或独立 API。

本次并未支持 Gemini 原生入口、Realtime/WebSocket、multipart 转录/翻译/图像编辑、视频生成及异步任务 API。完整矩阵和对应官方协议依据见对比文档。

Chat 音频历史中的供应商私有 `audio.id` 不能跨供应商重放，请携带实际音频输入或文本转录；Responses 工具结果内的音频/视频/PDF 不进行有损降级。二进制语音保留上游声明的响应长度，传输不足时客户端可以检测截断；已经输出后只关闭失败连接，不重试、不向音频尾部拼接 JSON/SSE。

第三方远端供应商复用已保存的 HTTP／HTTPS Chat 地址与 Key，不因 HTTP 协议阻止入池。Base URL 不接受内嵌凭据、查询或片段；本机上游仍禁止，避免回到自身代理。OpenRouter 免费目录仍限官方 HTTPS 地址，不能通过 HTTP 绕过免费目录校验。重定向不携带任何密钥继续请求。本机代理仍要求本机令牌，客户端供应商凭据不透传。模型池只持久化供应商 UUID 和模型元数据，文件通过 `PrivateFileWriter` 原子写入、权限 0600，使用 `FilePaths.freeModelPoolFile` 随 dev / release 隔离。损坏或未知版本文件保留原样，不自动覆盖。

发现目录的连接选择将地址与 Key 相同的 Claude Code／Codex 配置显示为一个共享连接；选中时沿用原供应商 UUID，不合并或改写保存的配置、模型池成员和并发额度。不同 Key 的连接保持独立，显示来源和配置标识，搜索支持来源与主机名。

## 实时路由图

上方「请求调度」将队列可视化为排队调度、分发连接、等待首帧、流式输出四个阶段。请求标记随真实阶段移动，输出事件产生返回脉冲；宽窗口为直线、窄窗口为连续弯道。入队、执行和备用等待使用同一请求标识。每阶段最多直接绘制八个标记，节点显示实际总数，点选可检查停留请求、供应商、难度、队列位置、等待时长及备用等待。队列位置表示当前顺序，实际调度仍是最早可运行请求优先。

调度图提供并发占用槽、等待字节、重试数量与最近结束的尝试，空闲时无动画。Core Animation 承接移动与输出脉冲，SwiftUI 不逐帧绘制。减少动态效果、离开可视范围或窗口遮挡时停止运动与脉冲；时长计时只在打开的信息浮层且窗口可见时更新。队列快照只在内存保留至多 1024 个等待项的请求标识、供应商 UUID、路由分类、排队时间及超时点，不持久化正文或凭据。

Auto 网关采用「请求 → 难度 → 模型」拓扑。档位与连线来自模型池配置，点击模型可修改承接档位；列表支持搜索、优先级调整和能力编辑。设置与接入示例在独立浮层，已有供应商提交在独立编辑器。

蓝色流动由真实转发事件驱动：建立连接、收到响应头、收到有效输出帧。开始输出后流向返回方向；成功短暂显示绿色，失败显示红色，备用切换显示下一条实际尝试。取消停止动效。事件只在内存保存请求标识、成员标识、阶段、档位与时间，不附带提示词、输出内容或密钥。输出更新最多每请求每秒八次，不代表 token 速率。

关系图每页五个模型，优先保留实际请求中的模型与最近两次完成尝试，最多九个节点。列表懒加载，不因输出帧重绘未变化的行。Core Animation 负责流动与脉冲；页面离开可视范围、窗口被遮挡或开启「减少动态效果」后停止动画，保留静态状态文字。无请求时不模拟流量。

`python3 Tools/render-model-gateway-preview.py` 使用合成数据与离屏原生视图生成浅色、深色、最小窗口、长名称、空池和大量模型预览，验证动画生命周期和列表更新范围，不启动应用或请求真实供应商。`make test TEST=free-model-gateway` 以本机模拟上游检验真实转发事件与备用切换。

发现任务归应用生命周期所有，离开模型页不会停掉已启用的发现计划，关闭定期发现或退出应用会取消任务。页面只有可见时每三秒读取一次路由状态，不重复发起发现。

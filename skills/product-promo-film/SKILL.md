# 产品宣传片制作

把真实产品界面编排成可阅读、有空间关系的动态叙事，并保留可再次编辑的时间轴与生成流程。默认沿用项目已有技术、素材和交付约定；片长、章节、主题与音乐服从当前用户要求。

## 先定位，再选择编辑方式

读取项目规则、影片制作说明、现有生成脚本、播放器和 README。观看现有影片，抽查主要章节与章界；源代码不能代替视觉检查。核对当前产品功能、素材来源、演示数据以及用户已经认可的视觉方向。

- **版本更新**：刷新真实 UI 素材，确认新功能改变哪些章节、尺寸和字幕，保留仍合适的镜头语言。
- **局部编辑**：确定受影响区间及跨章共享元素；只有时间轴、帧数和素材基线一致且完整帧缓存存在时，才局部替换帧后整体编码。
- **完整重做**：先写分镜与动效规格，低成本验证各段入场、停稳、展开和退出，再全量生成。

ClaudeBar 项目读取 [references/claudebar.md](references/claudebar.md)，以仓库当前文件为事实来源。其他项目按以下方法适配，不要求复制 ClaudeBar 的天气开场或固定 66 秒片长。

## 设计与实现

1. **建立叙事**：每个章节回答一个产品问题，指定真实界面、读者应看到的细节、主动作及落点。规划章节间共享物体或构图关系。动画中的概念分层需要与实际产品交互区分。
2. **准备真实素材**：优先用生产视图与固定演示数据渲染；有现成截图时核对版本与完整性。不要用 AI 重画 UI 的文字、数字或布局。标题栏、设备边框和场景可独立构造。禁止真实账号、密钥和私人对话进入素材。
3. **构造空间动效**：阅读 [references/motion-and-review.md](references/motion-and-review.md)。用透视、深度分层、遮挡、接触阴影与差速运动建立空间关系，保留可阅读的正面停稳阶段。运动丰富程度由叙事决定，不以持续晃动替代设计。
4. **按时间渲染**：让 `render(t)` 直接决定布局、样式、滚动与透明度，可跳到任意时刻和回跳。预先解码纹理；使用完整场景截图。固定或预生成噪声，不使用实时钟驱动画面。CSS 3D、Canvas/WebGL 或现有视频框架按项目选择。
5. **检查后编码**：先检查关键帧和短动作片段，再渲染完整序列。更改片长或章节时，同步字幕、章节按钮、预览摘录、封面时间点及文档；编码前验证连续帧数量，防止使用旧帧拼接。
6. **交付并整理**：交付影片、轻量动态预览、封面、必要介绍图与可编辑源文件。项目使用播放器时验证移动布局、字幕、章节跳转和 Range 请求。清理确认废弃的调试稿与中间缓存，保留生产渲染工具；清缓存后说明局部重渲染需要先重建帧序列。

默认可用 H.264 / yuv420p / faststart、1080p / 30fps 作为兼容交付基线，但以项目及用户需求为准。没有音频时不声称含配乐。

## 验收与汇报

视觉验收按 [references/motion-and-review.md](references/motion-and-review.md) 检查。使用技能目录下的 `scripts/inspect_video.py` 核对视频编码、尺寸、帧率、时长及帧数；必要时用 `--decode` 完整解码。自动化通过不能替代观看成片。

报告实际完成的编辑、观看/测试范围、输出路径及剩余限制。不要因脚本成功就宣称画面已检查；未执行的全量渲染或声音验收应明确说明。渲染期间持续告知进展，不承诺未经测量的完成时间。
